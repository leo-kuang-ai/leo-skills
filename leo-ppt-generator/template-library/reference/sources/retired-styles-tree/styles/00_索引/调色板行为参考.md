# 调色板行为参考(14 家族)

> 来源:academic-ppt-master 仓库 image-palettes 规格书(快照 2026-09-01,MIT,经 LLM 提炼)。
> **落位说明**:本库图表系列色序另由 `scripts/chart-palette-pool.json` 承担(机械 HEX 序列,
> 源 echarts/ppt-mcp);本页是**整页用色行为**规格——比例、角色、气质、渲染兼容——两者
> 口径不同,故独立成文档不并池。
>
> **颜色行为 ≠ HEX**。每个家族只约束「deck 的既有 HEX 怎么用」:谁主导、谁强调、
> 底场占多少、气质读感;具体 HEX 由品牌侧(`10_品牌身份`)或 deck 合同替换。
> 示例锚为源 fewshot 演示值,**示例数字仅为语法演示**,成品须换真实品牌色。

## 使用方式

1. 选定视觉风格(01)与渲染(08)后,按下方 14 家族速查表选定调色板家族(家族×渲染的兼容建议见文末 C3 配对小表);
2. 在 deck 合同登记 `palette_family` 名称 + 品牌 HEX 三元组;
3. 按该家族「行为纪律」句执行比例与角色;brief 的 `color_palette.rule` 已内嵌对应纪律。

## 渲染兼容要点(提炼自各家族矩阵)

- **照片系**(企业摄影/生活方式照):jewel-tone ✓✓(奢华调色)、dark-cinematic ✓✓(氛围)、
  warm-earth ✓(暖调)、earthy-dusty ✓✓(Morandi 调色)、tech-neon ✗(气质相冲)。
- **平面系**(扁平几何/矢量插画/丝网印刷):cool-corporate ✓、vivid-launch ✓✓、
  duotone ✓✓、mono-ink ✓✓、jewel-tone ✓(限量海报奢华)。
- **手绘系**(手绘笔记/黑板粉笔/剪纸层叠/水墨):macaron ✓✓(粉彩粉笔/粉彩剪纸)、
  warm-earth ✓、mono-ink ✓(水墨笔记域);tech-neon / vivid-launch 通用 ✗(依赖饱和度,气质错)。
- **仪表盘/数字 UI**:tech-neon ✓✓、dark-cinematic ✓、cool-corporate ✓;
  jewel-tone ✗(数据 UI 与奢华相冲)、mono-ink ✗(有意反数字感)。
