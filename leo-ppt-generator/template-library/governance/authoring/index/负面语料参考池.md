# 负面语料参考池（constraints.negative 词条池）

> 来源：huashu-design 审美禁区三步协议，思想级改写（无授权源，不复制上游
> 文本）｜快照 2026-09-02｜首期覆盖三派辐射家族组（东方意蕴/中式载体/质感
> 专业）+ 通用组；其余家族为扩展位，待新语料源按补货门补充。
>
> 机器可读契约：本文件的 `## <组名>` 二级标题 + 其下 `- ` 无序列表项即词条；
> `## 选用指引` 段不参与解析。`draft_negative_prompts.py --pool <本文件路径>`
> 按 current brief 的 `taxonomy.families` 匹配组名（`通用` 组对所有 brief 适用）。

## 通用

- 不要在单页混用三种以上字体家族，那会破坏任何视觉体系的字面秩序
- 避免无意义占位灰块与 lorem 式填充文本进入成图提示词
- 禁止装饰性元素跨越文字安全区，遮挡标题或要点首行
- 不要让强调色出现在三个以上互不相干的区域，强调会稀释为噪音
- 避免页面四角同时压重元素，视觉重心应唯一

## 东方意蕴

- 不要使用高饱和撞色破坏水墨低饱和基调，强调色至多一处且明度克制
- 避免几何硬边直切构图，留白过渡应是呼吸式的而非刀切式的
- 禁止把传统纹样当作满铺底纹使用，纹样只可作边角点缀或分隔
- 不要用立体阴影和金属光泽渲染水墨载体，那会变成廉价国潮贴片
- 避免书法字与黑体混排同一标题，两者气质互斥

## 中式载体

- 不要以居中对称布局塞满整页，载体类版式须保留器物轮廓的完整剪影
- 避免现代扁平插画语言混入传统工艺质感页，纹理笔触须统一
- 禁止红金配比超过 3:7，喜庆不等于整页正红
- 不要把朱红与桃红并置，传统色谱的红色系一次只用一种
- 避免对宣纸、绢帛类底纹做高对比锐化，纤维质感应是低反差的

## 质感专业

- 不要用渐变彩虹色破坏材质的中性基调，质感系强调色至多一档
- 避免大面积纯黑纯白对切，材质页的明度过渡应有中间灰阶承载
- 禁止塑料感高光出现在纸张、布纹、木纹类材质渲染中
- 不要让噪点颗粒覆盖文字区域，颗粒密度在可读区须降档
- 避免同一页出现两种主导材质（如金属+木纹）却不建立主次

## 选用指引

- **渐进补齐纪律**：仅在当前 brief 的 `constraints.negative` 不足 3 条且存在
  真实风险时补齐，不因历史欠账数字专项批量重写。以当前库 dry-run 为准；
  2026-09-20 检查的 320 个风格实体均已有至少 3 条约束。
- **工具派生**：`PYTHONPATH=runtime/src runtime/.venv/bin/python
  scripts/draft_negative_prompts.py --pool` 默认只读；自身 `visual_language` 中的
  显式禁止句优先，池词条仅补缺口。`--limit` 同时限制预览与写入候选数。
- **写入范围**：`--apply --library-root <v2-library>` 必须明确目标库，复用文件
  CAS 与 catalog 发布事务；身份和其他内容不变。跨库池、软链接、输入漂移、
  缺 current 均拒绝；当前 v1 delivery 不能由本工具隐式升级。
- **新风格入库**：起草 `constraints.negative` 时按 `taxonomy.families` 查池，
  池词条是起点，仍须对应风格自身风险；不从目录名推断家族。
- **扩展位**：新增语料源按 style-candidates.md 补货门评估；非通用组名须为
  当前库已声明的 taxonomy 家族名称。
