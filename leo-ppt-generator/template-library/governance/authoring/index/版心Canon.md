# 版心 Canon(全库网格唯一真值)

> 定位:**版面结构 token 的单一真值层**——边距、栏格、字阶刻度、安全区、hairline 全部
> 在本文定义一次,`template-library/canonical/layouts/` 各骨架与结构轴只许引用 token,**不得自造数值**。
> 来源:大师评审团 R12 决议(Vignelli 判据:「把结构定一次,让它处处显形」),数值
> 从既有版式反推归一(P12 负 margin hack 显形出的 5vw/4.4vh 版心即本表 token)。

## 一、版心 token(16:9 画布)

| Token | 值 | 语义 |
| --- | --- | --- |
| `page-margin-x` | 5vw | 左右版心边距(任何内容不得越出,装饰元素同样) |
| `page-margin-y` | 4.4vh | 上下版心边距 |
| `safe-bottom` | 93vh | 主内容最低处;距画布底 ≥3vh 呼吸,不触分页 nav |
| `grid-cols` | 12 栏 | 内容网格;gutter 见 `grid-gutter` |
| `grid-gutter` | 2vw(桌面)/ 3vw(高密度) | 栏间距;卡片间距用 grid gap,不叠 margin/padding |
| `hairline` | 1px `--border-subtle` | 分隔线唯一粗细;2px+ 线须有语义理由 |
| `section-gap` | ≥9vh | 章节级标题与下方内容的最小间距 |

## 二、字阶刻度(离散取值表,不是连续自由值)

| 刻度名 | vw(16:9) | 2560 画布 px | 用途 |
| --- | --- | --- | --- |
| display-xl | 11.6vw | 297 | 封面主标(双约束 `min(11.6vw,19vh)`) |
| display | 9.2–9.6vw | 236–246 | 宣言/收尾宣言(限高 `min(9.2vw,15vh)`) |
| h1 | 8.4vw | 215 | 页标题 |
| h2 | 7vw | 179 | 区块标题(现存豁免值,新写用 6.8vw=174px) |
| h3 | 4–5vw | 102–128 | 卡片标题 |
| body | 1.7–2.2vw(≥44px@2560) | 44–56 | 正文(字号下限见通用设计规范双口径) |
| caption | ≥1.1vw(≥28px@2560) | ≥28 | 卡片说明/图注 |
| meta | ≥0.9vw(≥24px@2560) | ≥24 | kicker/meta/图表标签 |

- 新写版式/风格的字号**必须从本表取值**;现存互异数值(见 lint 豁免清单)为登记豁免,
  逐步收敛。
- 字重纪律(越大越轻/三档表情)与行高阶梯见
  [`通用设计规范.md`](通用设计规范.md) 排印铁律,本表只管刻度。

## 三、双约束与对齐

1. 大字号一律 `min(Xvw, Yvh)` 双约束且 **Y ≥ X × 1.6**(高度余量不足会被截断)。
   (P20 曾用 16vh/13vw=1.23,已修为 21vh。)
2. 不二次叠加水平 padding(基础层已带版心边距,再叠=双倍内缩)。
3. kicker 在大标题**上方**(上下结构),不左右挤。
4. 子元素间距用 grid `gap`,不叠 margin/padding。
5. 版式数值落 **0.4vw 模数**(9.6/9.2/8.4/11.6 均为 0.4 的整数倍);现存非模数值
   (7vw/13vw 等)为登记豁免,新写值不得新增豁免。

## 四、Lint 与豁免纪律

- `scripts/lint_layout_grid.py` 扫描版式资产中的全部 `Nvw/Nvh` 数值:
  - 双约束比值 < 1.6 → **error**(必须修);
  - 数值不在 0.4vw 模数 → **warning + 豁免登记**(现存值存量豁免,新文件新增即 error)。
- 豁免不是免死金牌:每个豁免值都有收敛目标(见 lint 输出的豁免表),版式文件重写时
  必须落刻度。

## 五、与既有文档的关系

- [`通用设计规范.md`](通用设计规范.md) 第八节「版式对齐」的对齐法则以本表为数值源。
- `template-library/governance/rules/layouts/01_常犯错误.md` 的 Swiss 对齐法则与本表一致,数值冲突时**以本表为准**。
- 结构轴只管画布比例;页级骨架真值在 `template-library/canonical/layouts/`（见通用核心的映射声明）。
