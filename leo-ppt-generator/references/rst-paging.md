# RST 分页启发式（8 关系轻量版）

> 加载阶段：`execute` + Route=generate、进入大纲制作阶段且材料多段/结构复杂/
> 学术长文时读取，与 `deck-master.md` 同批；不进入口 / Route 判断 / advise 阶段。
> 本文件全部为 **advisory**：不进 `check_master_contract.py` 硬校验，确认摘要中
> 呈现"分页依据"一句即可。

RST（Rhetorical Structure Theory）关系在这里只借分页启发式思想（ArcDeck，MIT，
思想改写、表述原创），**不做完整树解析**：把原材料按 8 种关系词表（封闭）标注
分组边界，回答"哪些内容必须同页、哪些必须拆页"。

## 8 关系封闭词表

| 关系码 | 中文对照 | 一句话语义 |
| --- | --- | --- |
| `elaboration` | 细化 | 核心段与展开细节 |
| `explanation` | 解释 | 原因/机制/怎么运作 |
| `context` | 背景 | 场景、前提、相关工作 |
| `purpose` | 目的 | 动机、要解决的问题 |
| `evaluation` | 评价 | 局限、对比结论、批评 |
| `organization` | 组织 | 主题句、总-分结构总起 |
| `joint` | 并列 | 同级并列项（多要点） |
| `same-unit` | 同单元 | 本来是一个单元被排版切开（如一张表/一个推导链） |

词表封闭：大纲/母版标注只用上述 8 码，不自造关系码。

## 分页启发式表

| 关系 | 分页规则 |
| --- | --- |
| `elaboration` / `explanation` | 核心段与其细化/解释段**同页**（拆开即断因果） |
| `same-unit` | **绝不拆页**（硬规则）：同单元内容整体进一页；放不下走降级顺序，不拆单元 |
| `evaluation` | 评价/局限内容**可独立成页**（长时优先独立） |
| `joint` | 同级并列 ≤4 段可同页，>4 拆页或改台账版式 |
| `context` / `purpose` | 常作页首（背景/动机开场） |
| `organization` | 作主题句与后续内容同页 |

## 与禅档位的双判据关系

禅档位管"一页装多少"（容量），RST 关系管"哪些内容必须同页/必须拆页"（结构）。
执行顺序：先按 RST 定内容分组边界，再按禅档位定每组页数与要点上限。两判据冲突
（如 same-unit 组内容超出档位容量）时按《学术图表证据规则》的图降级顺序处理
（拆图 / 减解释结构 / 升档），**不得拆 same-unit**。`section_priority` 表
（见 deck-contract 块）与 RST 分组天然对齐：节 = 关系分组的外层。
