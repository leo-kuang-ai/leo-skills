# 叙事方法论：融资路演（investor-pitch）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../rst-paging.md`](../../../rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../叙事拍库.md`](../叙事拍库.md)）。

一句话：融资叙事方法——把投资人从「为什么是现在」带到「为什么是这支团队」，
用证据而非形容词，让每个主张都能在尽调中存活。

## 1. 适用场景

融资 deck、投资人会面、demo day、合伙人/董事会 pitch、内部风险投资立项申请。

## 2. 页序骨架

节位序列（非页数模板——权重按轮次自适应：早期靠洞察与团队，后期靠增长与
单位经济；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 时机 | 为什么是现在（Why now） | 让此刻成为可能的真实变化（技术/监管/成本曲线/行为） |
| 痛点 | 问题（Problem） | 谁在受苦、今天代价多少、现状怎么凑合 |
| 解法 | 方案（Solution） | 所建之物与其解决机制（实物，非意图） |
| 实证 | 产品证据（Product evidence） | 真实界面/输出/部署；任何摆拍披露 |
| 动能 | 增长牵引（Traction） | 市场响应的诚实曲线（全历史+口径） |
| 模式 | 商业模式（Business model） | 定价、单位经济、回收（给算式不给断言） |
| 空间 | 市场机会（Market opportunity） | 自下而上推导，不用嵌套大圈 |
| 竞争 | 竞争（Competition） | 含在位者与现状；承认对方赢的地方 |
| 增长 | 上市路径（Go-to-market） | 可重复获客动作的证据 |
| 团队 | 团队（Team） | 相关履历与挣来的洞察，不做 logo 墙 |
| 财务 | 财务与计划（Financials and plan） | 预测挂到命名驱动因子与当前速率 |
| 要价 | 要价（The ask） | 金额+用途+里程碑+跑道，一页无疑义 |
| 附录 | 尽调附录（Diligence appendix） | 队列、口径、合约、管线（高密度备查） |

## 3. 节奏要点

- 每页一个主张，**标题写主张本身**（转发无讲解者也能读对）；指标与其定义同页。
- 已实现、已签约、管线内、预测**四类视觉分明**——预测绝不借用结果的信用；
  指标首次出现即定义且全场口径固定。
- **绝不埋没最强项**；市场规模给推导，风险主动呈现而非尽调防火墙式回避；
  过不了尽调的主张删除而不是软化。
- 主弧保持稀疏，密度只进附录。

## 4. 与论证模式轴的关系（正交声明）

- 本条管融资叙事的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **故事弧**（源声明 Preferred Mode: narrative；情绪弧线、悬念与人性化），
  要价/决策页辅**结论先行金字塔**。
- 与 `../13_页面语义/融资路演链.md` 的边界：页面语义轴提供**单页功能词表与
  页型链**；本条提供整场叙事骨架、轮次自适应权重与尽调措辞纪律——一拍可
  落在不同语义页型上，互不枚举。
- 不重叠：故事弧定「怎么证——情绪弧线说服」；本条定「从 why now 到团队的
  页序、四类主张分级与尽调存活纪律」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：市场（market）、问题（problem）、方案（solution）、增长牵引（traction）、参考文献（references）
- 节奏签名：投资人故事+财务主线（investor-story-with-financial-spine）、
  短断言+视觉证据（punchy-claim+visual-proof）
