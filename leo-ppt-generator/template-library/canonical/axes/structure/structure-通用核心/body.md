# 结构布局：通用核心（presentation_core）

**分类:** 09_结构布局

**画布:** 16:9 · **页面版式数:** 20

**定位:** A structure-only 16:9 system with 20 authored PowerPoint Layouts for general, editorial, image, process, and data presentations.

## 页面版式清单

封面 · 标题+内容 · 章节页 · 双内容 · 对比 · 仅标题 · 空白 · 内容+说明 · 图片+说明 · 主陈述 · 编辑分栏 · 三卡片 · KPI仪表盘 · 流程时间线 · 数据叙事 · 标题+图片 · 双图+说明 · 截图聚焦 · 图表洞察 · 表格总结

> **骨架真值声明**:本轴只提供「画布约束 + 页面类型清单」,页级骨架的唯一真值是
> `template-library/canonical/layouts/*/layout.json`（P1–P36）。映射:封面→P1 / 章节页→P3·P10 / 对比→P8 / 主陈述→P3 /
> 三卡片→P5·P13 / KPI仪表盘→P6·P20 / 流程时间线→P2·P11 / 数据叙事→P18·P21 /
> 标题+图片·双图+说明→P22·P30·P31 / 截图聚焦→P30 / 图表洞察→P7·P17 / 表格总结→P21。
> 未映射页型(编辑分栏/内容+说明等)按 `template-library/governance/rules/layouts/00_选版式P0原则.md` 就近选择,不在本轴另立骨架。

> 结构布局轴只约束「画布 + 页面类型清单」，不含品牌色/字体/图标（那些来自品牌身份轴或 deck colors）。
