# 数据新闻编辑风

**分类:** 01_通用母版 · 质感专业

**适用场景:**
- 财经 / 市场复盘 / 年度数据报告 / 数据驱动的解释性长文
- Bloomberg 终端与 Economist 新闻信息图气质的出版级密度
- 研报、行业数据密集汇报、market map

**三层配对建议(风格 ↔ 渲染 ↔ 调色板):**
- 视觉风格层:本风格(多栏微图网格 + 发丝线 + 源行常驻)。
- 渲染层:配 `杂志编辑`(editorial 信息图意象)或 `数字仪表盘`(终端感数据 UI 意象,深场版)。
- 调色板行为层:浅场配 `cool-corporate`(克制蓝金)、深场配 `dark-cinematic`(Bloomberg 终端);图表系列色必须同族 tints,数字颜色表义(涨/跌/风险/焦点)不装饰。

**可参考来源:**
- GitHub: M1n-n9/academic-ppt-master · references/visual-styles/data-journalism.md(规格书快照 2026-09-01,MIT;源规格「风格不带 HEX」,锚点取自配套 image-palettes/cool-corporate fewshot 示例)
