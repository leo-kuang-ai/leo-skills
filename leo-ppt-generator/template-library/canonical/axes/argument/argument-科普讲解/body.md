# 叙事方法论：科普讲解（science-explainer）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../../../references/rst-paging.md`](../../../../../references/rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../argument-叙事拍库/body.md`](../argument-叙事拍库/body.md)）。

一句话：面向公众的解释叙事——从听众熟悉的地面出发，用视觉类比一步步
搭起理解，最后**回到开场地面换个样子看它**；不以准确性换可达性。

## 1. 适用场景

科普讲座、公众解释、面向非专业受众的研究讲解、技术通识课、
面向大众的科学传播。

## 2. 页序骨架

节位序列（每一步挣得下一步；非本领域课程的章节顺序；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 起点 | 熟悉的地面（Familiar ground） | 听众已知或亲历过的经验起点 |
| 谜题 | 谜题（The puzzle） | 熟悉地面解释不了的现象——好奇的引擎 |
| 搭建 | 积木块（Building block） | 一次一块必要概念，标注简化处 |
| 类比 | 视觉类比（Visual analogy） | 类比图示（标注类比边界） |
| 机制 | 机制（Mechanism） | 真实机制的可视讲解 |
| 尺度 | 尺度与量级（Scale and magnitude） | 可感的尺度表达 |
| 证据 | 证据（Evidence） | 共识证据的诚实呈现 |
| 纠偏 | 常见误解（Common misconception） | 误解及其为何诱人 |
| 边界 | 知识边界（Edge of knowledge） | 共识/争论/猜测的分界 |
| 收束 | 为何重要（Why it matters） | 回连听众的生活与关切 |
| 延伸 | 再走远（Going further） | 延伸材料 |

## 3. 节奏要点

- 每页**搭建中的一步**，标题用平实语言写「想法」而非术语名；术语只在
  听众见过它命名的东西之后引入，且首现页带平实释义。
- 图与其承载的想法同页——需要上一页才能懂的图就是搭建断了。
- **一个想法讲透胜过五个提到**；引入顺序只服从理解的需要，不服从学科课程
  的章节顺序。
- 确立共识、活跃争论、猜测**三类用平实措辞分明**（不用外行解不开的含混对冲）；
  类比标注为类比并先说出它在哪失效；**简化靠省略细节，绝不靠说错**——
  简化会误导时就说明真相更复杂并指出方向；尺度与不确定性用听众能感的表达。

## 4. 与论证模式轴的关系（正交声明）

- 本条管公众解释的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **教学分解**（源声明 Preferred Mode: instructional；分解排序、概念先行），
  情绪线可辅**故事弧**（谜题-揭晓的悬念）。
- 不重叠：教学分解定「怎么证——分解排序的教学论证」；本条定「熟悉地面→
  谜题→回访的科普页序、类比边界纪律与共识/争论/猜测三分措辞」。
