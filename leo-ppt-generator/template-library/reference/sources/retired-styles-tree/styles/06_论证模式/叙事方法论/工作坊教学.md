# 叙事方法论：工作坊教学（workshop-teaching）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../rst-paging.md`](../../../rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../叙事拍库.md`](../叙事拍库.md)）。

一句话：**做中学（learn-by-doing）**的培训叙事——按「学习目标 → 完整走通的
示范 → 练习 → 诚实的理解检验」排序，让学员从「不会做」走到「能独立做」，
deck 既可现场用也可事后自学。

## 1. 适用场景

动手工作坊、技术赋能、入职课程、内训、tutorial、认证备考。

## 2. 页序骨架

节位序列（每轮循环的大小随任务难度而非固定课模板；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 目标 | 学习目标（Learning objective） | 学完后能**做**什么（可观察动作，非话题覆盖） |
| 准备 | 前置与准备（Prerequisite and setup） | 版本/权限/环境清单 + 验证步骤 |
| 概念 | 概念锚点（Concept anchor） | 行动所需的最小心智模型（标注简化） |
| 示范 | 完整示范（Worked demonstration） | 完整走通含不起眼的步骤（真实输入真实输出） |
| 练习 | 引导练习（Guided practice） | 任务+起点+成功条件+求助路径 |
| 纠错 | 常见错误（Common mistake） | 错误结果及其真实成因（不是训诫） |
| 备查 | 参考卡（Reference card） | 精确语法/参数/默认值（为查而非读优化） |
| 检验 | 理解检验（Understanding check） | 考应用不考回忆；答案可自查 |
| 收束 | 小结与下一步（Recap and next step） | 回连目标；如实指明下一能力 |

## 3. 节奏要点

- 概念**在需要用它行动的那一刻引入**；指令与其所需的一切同页——
  绝不把程序拆到要求学员凭记忆衔接前步。
- 练习页与讲授页**视觉可辨**（学员回翻能找到）；参考卡高密度但严格网格，
  为查表优化。
- 规则、惯例、建议、个人偏好**四类分明**；展示常见错误及其诱因而非只给
  正确路径；简化标注为简化——真实情况更复杂时就明说，不留虚假完整感。
- 每个讲授页向前回连目标、向后指向学员要做的事；两者都不服务的背景内容删除。

## 4. 与论证模式轴的关系（正交声明）

- 本条管培训叙事的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **教学分解**（源声明 Preferred Mode: instructional；分解排序、学习单元聚焦、路标）。
- 不重叠：教学分解定「怎么证——分解排序的教学论证」；本条定「目标-示范-
  练习-检验的做中学页序、练习/讲授可辨节奏与四类主张分明」。
