## 进化机制（表头合同）

- **定位**：候补≠承诺入库。触发前不进主库、不进 style list。本表是库存设计
  （自主进化的弹药库），不是排期表。**独立可选风格不设数量上限**（300 硬顶已于
  2026-09-02 经 owner 决策退役）；防膨胀由质量门组合承担，不靠数字上限。
- **驱动信号**（三类使用数据通道，任一持续出现即评估补货）：R-30 分角色组合
  （封面/内页档位家族缺口）、R-64 推荐落盘反馈（家族 decay 持续偏高＝覆盖弱）、
  R-55 负触发与点名落空（相近候选机制记录的落空词；当前三通道中唯一基本可用，
  R-64/R-30 归 R3-4 择优批）。
- **补货门**（五步流程，owner 决策 2026-09-02 起不再含数量余量检查）：
  1. **信号确认**：点名落空（或结构性缺口，如新主风格无渲染锚）持续出现；
  2. **四重去重**：概念级 SKIP／色板指纹 family_duplicate／同板并入 variant_of／
     跨源同名同族合并；
  3. **精选与许可核验**：金样板先例精选 + 许可口径（授权源直引 / 无授权源思想级
     改写）逐源确认；
  4. **金样板三页 + 视觉风格配对预览行**：不裸入库（落位沿用
     `samples/reference-golden/<源名>/` 先例）；
  5. **治理 lint + audit 出口**：六条治理 lint 全绿 + audit 簇数门（疑似同族簇
     当前基线 10、回退门槛 >20——10 是当前值不是门槛）。
- **金样板与预览义务**：凡从本表入库，同批补 3 页金样板与视觉风格配对预览行。
- **许可红线**（沿袭进货批合同）：GordenPPTSkill（稻壳来源）与 dashi-ppt-skill
  （AGPL）已于 2026-09 获项目负责人线下授权——Gorden 按金样板先例精选收录 +
  全量映射登记（见 `samples/reference-golden/gorden/README.md`），dashi 授权明示
  范围为 theme01-12 色板直引（容量词汇按"数值档位=事实数据可引、表述=思想级
  改写"保守口径处理）；其余无授权源仍只做思想级改写，不搬文本与素材。
- **登记字段**：源项目｜C 批实收｜净新余量｜精选建议｜触发条件｜去重注意
  （六字段，快照口径）。
