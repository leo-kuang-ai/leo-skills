# 叙事方法论：创意提案（creative-pitch）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../rst-paging.md`](../../../rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../叙事拍库.md`](../叙事拍库.md)）。

一句话：把一个创意锚在**真实洞察**上，再让它「活」在它将要出现的每一个地方——
先证幅度，后证完成度，最后收在作品将如何被评判。

## 1. 适用场景

广告/品牌提案、创意比稿、campaign 提报、创意方向汇报——面向客户决策的
创意作品叙事。

## 2. 页序骨架

节位序列（非页数模板——页数按材料量与禅档位定；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 洞察 | 受众真相（Audience truth） | 作品立足的真实人群洞察（一手证据，非改写的 brief） |
| 任务 | 任务（The task） | 洞察制造的张力或任务 |
| 思路 | 策略思考（Strategic thought） | 策略建构——保持足够短，创意才会惊喜 |
| 创意 | 创意（The idea） | 一句话落定创意 |
| 主执行 | 英雄执行（Hero execution） | 主视觉/主物料的完整呈现 |
| 延展 | 幅度与延展（Range and extension） | 创意在各触点的活法——先证幅度后证打磨 |
| 探索 | 身份探索（Identity exploration） | 标识/语汇方向的探索面 |
| 质感 | 调性与工艺（Tone and craft） | 声音、调性与制作质感 |
| 场景 | 环境与语境（Environment and context） | 出现环境（媒介/空间/时刻） |
| 现实 | 制作现实（Production reality） | 可产性、档期、权利披露 |
| 收束 | 度量（Measurement） | 作品将如何被评判 |
| 附录 | 领地参考（Territory reference） | 参考与权利说明 |

## 3. 节奏要点

- 每页**一个时刻、一个执行、一个思考片段**；让作品占据页面，解释压到
  最短的一行——被长篇解释的创意页就是失败的创意页。
- 两个竞争执行**绝不同页**；创意与其理由不争夺同一视觉重量。
- 洞察、创意、执行、制作现实四者措辞分明；mock 场景与占位内容如实标注，
  **绝不暗示不存在的合作、背书或媒介投放**。
- 长篇解释与理念阐述不进入弧线，落附录。

## 4. 与论证模式轴的关系（正交声明）

- 本条管创意汇报的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **视觉展示**（源声明 Preferred Mode: showcase；图/作品主导、揭晓结构），
  情绪线可辅**故事弧**。
- 不重叠：视觉展示定「怎么证——以作品为证据的展示论证」；本条定「洞察→创意
  →延展的创意叙事页序、幅度先于打磨的节奏与权利诚实纪律」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：作者声音（voice）、田野发现（field-findings）、图示注解（annotated）
- 节奏签名：短断言+视觉证据（punchy-claim+visual-proof）、
  文章式跨页+停顿（essay-spread-with-pauses）、人尺度叙事（human-scale-narrative）
