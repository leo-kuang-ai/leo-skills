## 标题公式库

按读者视角分五类。公式给出的是结构，不是答案：先按 `copywriting.md` 写前合同确定唯一动作和读者，再套结构产候选，最后用测试工具过滤。例句仅为结构示范，发布前必须替换为有真实证据支撑的数字与承诺。

### 成果型

| 公式 | 中文示例 |
|---|---|
| {成果}，不用再{痛点} | 看清用户在哪一步流失，不用再对着报表猜 |
| 通过{产品机制}拿到{成果} | 通过识别来访公司名称，拿到更多有效线索 |
| 把{输入}变成{成果} | 把这一次成交，变成下季度的回头客 |
| {时间段}内完成{成果} | 3 个工作日内拿到企业信用报告 |
| 从{起点}到{成果}，只差{一个动作} | 从零到第一门付费课程，只差一次系统梳理 |
| {成果}，无需{常见代价} | 不写一行代码，上线自己的官网 |
| 从{既有资源}获得{收益} | 从现有流量里，再挖出一层收入 |
| 像{可敬佩的参照}一样{动作}{对象} | 像头部品牌一样做新品发布 |
| {成果}所需的一切，都在这 | 发布一门付费课程所需的一切 |

### 痛点型

| 公式 | 中文示例 |
|---|---|
| 再也不{糟心事} | 再也不漏掉一条销售线索 |
| {点名痛点的问句} | 退货流程也让你等到心累吗？ |
| 别再{痛点}，开始{收益} | 别再追着发票跑，让回款准时到账 |
| 终于有{品类}能{收益} | 终于有款记账软件，不用每月手工对账 |
| 每天{场景}都在{损耗}，是时候停下来算这笔账 | 每天两小时手工搬数据，是时候算这笔账了 |

### 受众型

| 公式 | 中文示例 |
|---|---|
| 给{人群}的{产品类型} | 给跨境电商卖家的店铺分析工具 |
| 给{人群}用来{用途}的{产品类型} | 给远程团队一起梳理需求的共享白板 |
| 专治{人群}的{具体困难} | 专治独立开发者的定价纠结 |
| 你不必{技能}也能{成果} | 不懂 SEO，也能把关键词做上首页 |
| 为{人群}打造的{特质}{品类} | 为独立开发者打造的轻量记账模块 |
| {最简单路径}达成{成果} | 记录时间开销，最不费力的方法 |

### 差异化型

| 公式 | 中文示例 |
|---|---|
| {与常规相反的方式}达成{成果} | 把兴趣变成收入，不用先辞职 |
| 那个{关键差异点}的{品类} | 会自动同步客户动态的 CRM |
| 如果你能{理想成果}，会怎样 | 如果每单成交都快三天，会怎样？ |
| {品类}的反直觉真相：{差异点} | 选品工具的反直觉真相：数据越少，决策越快 |
| 同类还在{普遍做法}，它已经{差异做法} | 同类还在人工核价，它已经按小时自动重算 |

### 证明型

| 公式 | 中文示例 |
|---|---|
| {数字}位{人群}用{产品}做到{成果} | 4,200 位自媒体作者用它排好每一篇图文 |
| {核心收益的直接陈述} | 线上会议里，对方听清每一个字 |
| {场景}之前 vs 之后 | 接入前每周对账 6 小时，接入后 40 分钟 |
| {权威背书}也在用{产品}解决{问题} | 三家上市公司用它替代手工报表 |

证明型的数字与背书必须可追溯到真实来源；没有证据时降级为成果型写法或补齐证据，不得虚构。

### 战术辨析与失效条件

标题公式回答「怎么写」，本表回答「这类钩子什么时候失效、与哪类易混」。命中失效条件的候选回到公式重写或降级为占位（来源：marketing-os（MIT），快照 2026-08-31；中文化改写自其钩子战术双列表，非逐条翻译）。

| 战术 | 易混淆于 | 失效当 |
|---|---|---|
| 问句钩子 | curiosity gap：邀请作答 vs 扣留信息 | 能被一个「不」直接答掉 |
| 点名圈定（callout） | 身份镜像：点名处境 vs 镜像自我形象 | 圈定比目标人群宽，读者觉得「说的不是我」 |
| 数字钩子 | 社会证明：单点事实 vs 群体验证 | 数字是圆整数、无来源或不可信；无源数字永不虚构，降级为 `[NEED: 数字]` 占位 |
| 社会证明 | 权威背书：规模 vs 深度 | 数字不可证——宁可少而可溯，不编大数 |
| curiosity gap | 问句钩子：扣留信息 vs 邀请作答 | 兑不了现——标题开支票、正文兑不出，烧掉的是整个账号的信任 |
| 反直觉主张 | 对比公式：论证 vs 并置 | 攻击的「常识」是稻草人，读者根本不认领 |
| 身份镜像 | 点名圈定：自我形象 vs 处境 | 变成奉承读者，而不是认出读者 |
| 演示钩子 | 结果主张：过程 vs 结果 | 只演示了机制，没演示读者要的结果 |
| 紧迫/稀缺 | 时间延迟杠杆：为什么是现在 vs 多快见效 | 稀缺是假的——与反操纵红线的禁假稀缺同条同源 |
| 权威背书 | 社会证明：深度 vs 规模 | 权威与主张不同域，头衔压不住内容 |

载体不重复：封面图、标题、副题各承载不同负荷，文字复述画面已表达的内容即浪费一格。

### 修辞公式（双关与留白）

与上方句式公式轴不同：句式公式填槽位出标题，修辞公式让一句话获得第二层含义（来源：xiaoma-durex-copywriter（MIT），快照 2026-08-31；克制频率为编辑纪律非统计目标）。

| 修辞 | 一句机制 | 迁移模板 |
|---|---|---|
| 词义劫持 | 行业黑话字面化，B 端最适用 | {黑话}回到{字面日常义}：回滚、熔断、冷启动都可以劫 |
| 场景移植 | 配角物件第一人称开口 | 「我是那把总被落下的伞。」——无实体产品最好用 |
| 宜忌体 | 对仗两行，宜与忌各一句 | 宜{正确动作}，忌{最常见的误用} |

频率红线：谐音一条文案只用一次，用两次就变顺口溜；反向克制（在期待你抖机灵的场合说朴素真话）全年 ≤5 次，用多就成了鸡汤号。产出后先过「双层语义与借势质检」再交付。

## 测试工具

公式给形状，测试判断这行字是否真的在工作。候选产生后逐项过滤，不通过的回到公式重写。

### 「现在你可以…」测试

任何标题或收益句前，脑内加上「现在你可以…」。加完后同时满足「有吸引力」和「真实」才算过关；读起来空洞、理所当然或牵强的，重写。原理：这个前缀强迫文案进入读者的世界——必须说出读者此前没有、现在拥有的具体新能力，功能腔和空话会当场塌掉。

| 原句 | 加前缀后 | 判定 |
|---|---|---|
| 强大的分析平台 | 现在你可以…拥有一个强大的分析平台 | 不过关：只是描述，不是新能力 |
| 看清哪些公司在访问你的网站 | 现在你可以…看清哪些公司在访问你的网站 | 通过：具体且真实 |
| 让工作流更顺畅 | 现在你可以…让工作流更顺畅 | 不过关：空洞、无法证伪 |

用法是过滤器不是公式：先按公式库起草，再全部过一遍该测试，留下幸存者。

### Human Action Model 三拍

人只在三件事同时成立时行动。首屏叙事必须三拍齐备，缺一拍读者就停住：

1. **当前不适**：用读者自己的话命名的切身问题，读者要能认出「就是我」。
2. **更好愿景**：不适消失后，可清晰想象的状态。
3. **行动路径**：相信「这一步」能弥合前两者的差距；产品是桥，CTA 是过桥动作。

没有不适就没有动的理由；没有愿景就没有目的地；没有路径就没有理由相信你是那座桥。

| 拍 | 通常落在 | 示例 |
|---|---|---|
| 当前不适 | 眉题、副题或问题式主标题 | 发会议邀请链接，不该让你觉得欠了对方人情 |
| 更好愿景 | 主标题或副题 | 让约时间这件事，对双方都体面 |
| 行动路径 | CTA 及紧邻证据 | 免费开始预约 |

落地页其余区块的任务是逐拍做实：问题区做实不适，收益区做实愿景，原理区与证据做实路径。

### Perception Gap 分流

同一句卖点，对一个细分是吸引力，对另一个细分是红旗。差距不在你写了什么，而在读者透过自己的风险偏好听到了什么。解法不是把措辞调软，而是**分流**：先分人群，再换价值主张。

| 卖点原样 | 早期采用者听到 | 风险厌恶型客户听到 |
|---|---|---|
| 周末就能上线 | 速度与势能 | 不成熟、不稳定 |
| 全新的做法 | 创新优势 | 未经证明 |
| 企业级安全与 SLA | 臃肿、贵、慢 | 可靠、可信 |
| 大企业都在用 | 不是为我做的 | 风险已被验证 |

同一产品服务两类人群时，不要折中成两边都不痛不痒的中间态：拆页面或拆人群入口，让每类读者读到属于自己的那版真话。

### 双层语义与借势质检（第四个）

双关与借势文案的过滤器：一句话必须同时成立于表层（热点/场景字面）与里层（产品），作者只写表层，里层由读者自己跳过去（来源：xiaoma-durex-copywriter（MIT），快照 2026-08-31；边界条件为我方改写）。

- **一跳可达**：把联想链画出来，箭头超过一个就是失败，重写。最稳的一跳是让产品自己待在画面里当第二层——并置即懂，不需推理。
- **点破即死**：只要在文案里解释了里层，这条就废了。写完表层那句就停。
- **落点是「你」**：借势落点必须回到读者处境或行动，落在产品参数上的是硬蹭。
- **五类钩子判贴**：专有名词、核心动作、关键属性、数字、场景——热点至少对上一类才做，对不上就放弃，不硬蹭。

边界（改写自上游红线，与反操纵红线对齐）：「点破即死」是修辞纪律，不是事实豁免——里层暗示的产品属性与明示主张过同一证据账本，里层指向产品不具备的属性即整条重写；强合规品类（医疗、金融、法律）与产品状态文案禁用双关，只走 `copywriting.md` 的状态文案规则；题材五条硬边界照随——不碰灾难/事故/死亡/疾病（公益除外）、不物化女性、不对具体真人做性暗示（尤其未成年）、不蹭悲情热点、迁移到非成人品类时里层指向产品价值。

## 七轮编辑法

对已有文案做多轮编辑时，按固定顺序做七次单维度扫描，每轮只处理一个维度；每轮改完回扫之前各轮，确认没有引入新问题。不要试图一次全修——那正是漏检的原因。

1. **清晰度**：指代不明、行业黑话、歧义句、一句话塞多个意思、限定词淹没重点。先标注不改动，再逐处给编辑建议。改完确认「一节只讲一个主张」「对读者说话」未被破坏。
2. **声音语气**：正式度漂移、人称混乱、幽默错位、品牌词不一致。朗读检查突变点。改完回扫清晰度。
3. **「所以呢」测试**：对每个主张追问「所以呢」，直到落在读者的具体利益上。功能没有收益桥的，补「这意味着…」；空有气势落不到利益的，改写或删除。
4. **证明它**：每个需要证据的主张附近要有可追溯证据——具名证言、案例、数据、第三方背书；没有证据就补证据或软化主张。此轮与本技能证据账本同构：主张必须能映射到来源，禁止编造证明。
5. **具体化**：空泛词升级为数字、时限、实例；无法具体化的内容多半是填充，删。升级表：

   | 空泛 | 具体 |
   |---|---|
   | 帮你省时间 | 每周省出 4 小时 |
   | 很多客户在用 | 2,847 个团队在用 |
   | 很快见效 | 14 天内见效 |
   | 优化你的工作流 | 报表时间从 4 小时压到 1 小时 |
   | 服务响应快 | 2 小时内人工响应 |

6. **情感增强**：只在真实处着墨。刻画「之前」状态、写可感细节、讲微故事；情绪服务信息，不用于掩盖证据缺口或操纵。改完回扫具体化与证明它。
7. **零风险**：扫描 CTA 附近的全部犹豫理由——未回应的异议、隐藏成本、模糊的下一步；用真实的风险反转（保证条款、免费试用、随时取消）与信任信号回应。风险反转必须真实存在，不得虚构承诺。

完整七轮用于高 stakes 文案；小改动可按 `copywriting.md` 的 `point-edit` 姿态只跑相关轮次，不扩成整页审计。

### 迭代有界停止

多轮改写的停止纪律（来源：marketing-os（MIT），快照 2026-08-31）。**评分是启发式非实测**：来自评审视角的营销判断，不是测量出的表现——分数只用于定位当前最弱项，是软停止线索，不作放行门禁。

- 五视角速查（怀疑者/陌生人/竞品/买家/编辑，各 0-20 自评合计 100）：陌生人=冷读 3 秒是否成立；竞品=对手能否原样贴上自己 logo；怀疑者=第一个反驳会是什么；买家=掏钱的理由落在哪一句；编辑=哪一句最弱。
- 单点修复优先：每轮只修评审指认的那一个具体反对意见，修后复评，不顺手改别的。
- 目标 90+ 或最多 3 轮即停；已无具体反对意见可修即停——超出是打磨不是改进，与「只是不同而没有更好时恢复原文」是同一停止语义的两面。
- 自评 <70 的候选直接淘汰，不并列展示——弱选项稀释强选项。

## CTA 与落地页

### CTA 公式

**动作动词 + 所得 +（必要时）限定词**。

- 弱 CTA（避免）：提交、注册、了解更多、点击这里、开始使用。
- 强 CTA：开始免费试用、获取我的检测报告、看产品实测演示、创建你的第一个看板、下载完整清单。

按钮文案要回答「点下去我得到什么」；产品状态文案（错误/成功/权限）不套用说服公式，见 `copywriting.md`。

### 落地页六个核心区块

1. **首屏**：主标题 + 副题 + 主 CTA + 支撑视觉；副题补具体性，一到两句为限。
2. **社会证明条**：客户标识（可识别优先于数量）、关键数字、评分与证言片段；数字须真实可溯。
3. **问题/痛点区**：把读者的问题说得比他自己还准，让他认出处境，并点到不解决的代价。
4. **收益区**：3-5 个关键收益，不堆 10 个；每条 = 结果标题 + 一两句机制 + 可得时的证据。
5. **原理区（How it works）**：3-4 个编号步骤，每步 = 简单动词 + 该步所得；降低「看起来很复杂」的感知。
6. **最终 CTA 区**：复述价值主张、重复主 CTA、给风险反转。

首屏陈述转变（三拍），其余区块逐拍做实。功能清单式页面（首屏→功能 1→功能 2→…→CTA）是列表不是论证，改按六区块重排叙事。

## 价值等式与反操纵红线

### 价值等式

```text
价值 = (梦想结果 × 实现感知) / (时间延迟 × 付出牺牲)
```

读者拿「价值」与价格比较，价值高于价格才行动。多数「降价」诉求，实际是「抬高分子或压低分母」的诉求——价格是比较项，不是价值本身。

| 杠杆 | 含义 | 怎么动 |
|---|---|---|
| 梦想结果 ↑ | 读者真正想要的，通常在表面诉求之上一两层 | 具体命名结果；连到表面诉求背后的更大目标 |
| 实现感知 ↑ | 读者是否相信自己做得到 | 具名案例与数据、保证条款、可复述的方法论、给「和我情况类似」的同类证明 |
| 时间延迟 ↓ | 从购买到见效多久 | 设计更快的首次见效；压缩上手与端到端时间——不得承诺做不到的时限 |
| 付出牺牲 ↓ | 金钱之外的成本：时间、学习曲线、决策数、社交风险 | 代劳选项、预置默认、更少决策、更低学习成本 |

诊断：四个杠杆各按 1-10 诚实打分，最低分是当前约束，单次迭代只修最低杠杆。多数卡住的报价缺的是证明（实现感知），不是更多功能。

### 报价六组件

完整报价包含：核心交付物、加赠组件（让核心显得物超所值，但按真实价值标注）、保证（做不到时怎么办）、稀缺/紧迫（为什么是现在）、命名（这个东西叫什么）、价格与支付结构。常见失败：没有加赠、保证缺位或错型、稀缺是假的。

### 反操纵红线

以下红线与证据优先纪律并行，冲突时以证据红线为准：

- **禁假稀缺**：假倒计时、「仅剩 3 个名额」式谎言。短期涨数字，长期毁信任，直接不做。
- **禁无依据承诺**：「无效退款再赔」式保证先吃掉利润，兑付失败公开反噬。
- **禁价值膨胀**：没有可比对照的「价值 ¥X」加赠标注。
- **禁夸大禁用词**，中文对应表：

  | 上游禁用词 | 中文对应 |
  |---|---|
  | game-changing / revolutionary | 颠覆性、革命性、改写规则 |
  | disruptive | 颠覆行业 |
  | next-level | 更上一层、跨越式 |
  | 10x | 十倍提升、十倍增长 |
  | secret / hidden | 秘诀、不为人知的 |
  | what they don't want you to know | 他们不想让你知道的 |

- **数字纪律**：本文及上游出现的转化率、增长率数字未经核实，不得作为事实写入文案；文案中的数字一律走证据账本。
- 替代做法：具体数字、具名客户、可验证结果、真实时限。具体性胜过最高级。

## AI 痕迹词表（中文版）

营销与正式文案共同的模板腔。本表与 `chinese-editorial-protocol.md` 的 22 条特征互补：协议第 17 条已覆盖「然而/事实上/值得注意的是」类连接词堆叠，本表不重复，只补开篇、过渡、收尾与结构模式。命中后按上下文判断——准确术语、作者有意表达与真实引语保留。

| 类别 | 高频痕迹 | 处理方向 |
|---|---|---|
| 开篇模板 | 在当今数字化时代、在这个快节奏的时代、随着…的不断发展、想象一个…的世界 | 从具体事实、场景或问题直接开始 |
| 过渡模板 | 让我们深入探讨、这引出了一个问题、说到底、从根本上说、本质上、值得一提的是 | 直接进入下一层论述 |
| 收尾模板 | 总而言之、综上所述、综合来看、归根结底、在这个…的时代，… | 文章讲完就停，不强行升华 |
| 结构模式 | 「无论你是 X、Y 还是 Z」三连举例；「它不只是 X，更是 Y」；「把 X 想象成（一段精细比喻）」；「通过做 X，你就能 Y」开头 | 改为直接陈述与具体例证 |

英文原文案写作时的对应禁用表（that being said、it's worth noting、at its core、in today's digital landscape、let's delve into、in conclusion 等）同样适用；中英文混排稿件两表都过。

短文案语感纪律差集（来源：xiaoma-durex-copywriter（MIT），快照 2026-08-31；只补本表与 `check_prose.py` 未覆盖项，上游自述的句长统计不吸收——统计结果不是写作目标）：

| 纪律 | 要点 |
|---|---|
| 标点是语气不是语法 | 「～」轻佻、「。」斩钉截铁、「……」留白——按目标语气选，不当默认标点用 |
| 从不解释自己 | 「这就是…的力量」「背后的逻辑是」「之所以…是因为」零出现——解释即点破，与双层语义质检同律；「这意味着/换句话说」类已入 check_prose 硬停词，短文案同律更严 |
| 人称「你」为主 | 「大家/各位/用户」一出就是通知腔，不是对话 |
| 数字直接当词用 | 不加「多达/高达/整整」类量词修饰——数字本身扛住，修饰词只泄气 |
