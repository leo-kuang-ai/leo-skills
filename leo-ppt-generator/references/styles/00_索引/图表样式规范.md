# 图表样式规范(数据图表的坐标轴 / 图例 / 标签 / 网格线 / 诚实纪律)

> 定位:`11_图表语法`(结构)与 `07_信息图类型`(构图)的**样式上位规范**,数据版式
> (P6 KPI Tower / P7 H-Bar / P20 Ledger / P21 Tech Spec)的数值呈现纪律,也是
> [`通用设计规范.md`](通用设计规范.md) 的数据专项补篇。任何图表——mermaid 原生、
> 图片式 stylized、可编辑路线原生——先过本规范,再谈风格。
>
> 来源:2026-08-29 大师评审团 R4/R15 决议(Tufte 判据:data-ink、lie factor、
> 直接标注)与风格系统评审 §二.4 的合并落地。

## 一、数据墨水纪律(chartjunk 禁令)

1. **尺寸必须由数据授权。** 任何 bar / tower / 竖线 / 带宽,其高度、长度、宽度必须
   绑定 approved 真实数据序列;无序列授权的形状 = 编造数据,要么绑定真实序列、要么
   删除(不得称「装饰」后保留)。KPI 卡上出现数字即视为量化图形,同样受形状语法约束。
2. **lie factor ≈ 1。** 视觉尺寸变化比必须等于数值变化比。`06_KPI_Tower` 的
   `min-height/max-height` 钳制区间必须标注「非线性映射」;95/98/99/100 这类相邻值
   不得被渲染成数倍视觉差。
3. **概念骨架禁标数值。** 漏斗图的固定 15–25% 递减、金字塔的分层、等距时间线只是
   排版节奏——除非宽度/间距映射真实值,否则禁止在旁标注真实转化率/百分比。
4. **非数据墨水最小化。** 图标、边框、纹理、阴影不得侵占数据元素的相对面积;
   count-up / 滚动揭晓动画仅允许用于**引用级**数值(滚动会制造精确错觉,估算值禁用)。

## 二、置信度形状语法(三级标注的视觉层)

三级标注(引用/估算/示意,见 `image-deck-workflow.md` 第 1 步)此前只有文本语法
(括注小字);受众扫读图表时无法分辨证据强度。本规范补全形状层:

| 来源级 | 文本标注(既有) | 形状语法(本规范) |
| --- | --- | --- |
| **引用** | 有出处 | 实心填充 / 实线;数值无前缀 |
| **估算** | 括注「估算/经验值」 | 纹理或虚线填充 + 数值前缀「~」;同页混级时图例声明两级置信度 |
| **示意** | 标「示意」 | **禁入一切量化图形**(含 KPI 卡 / 塔 / 条 / 饼),只许文字修辞 |

- 同页混用引用级与估算级时,图例必须同时声明两级;判据:受众在半秒扫读中读出
  证据强度,不依赖括注小字。诚实的成本不由受众的近视承担。

## 三、坐标轴 / 网格线 / 图例 / 数据标签

1. **网格线退到最弱**:最浅灰 / hairline,只保留参考必需的线;无数据映射的网格删除。
2. **直接标注优先于图例**:数值/名称直标在数据点旁;图例仅在类别 > 6 或直标会碰撞时
   使用,且紧邻图表。
3. **坐标轴**:轴线与数据线线宽 1–1.5px(与 `08_图片渲染/数字仪表盘` 条款一致,
   全图统一,不出现 2px+ 粗轴);刻度稀疏;柱状图共零基线;纵轴截断必须画断轴符号。
4. **排序**:类别数据按数值排序,时间序列按时间;跨页同一指标同尺度。
5. **单位与口径**:轴与标签必须带单位;期间/口径随三级标注(引用级缺期间/口径/单位
   任一项,降级 `unknown` 求证,不得先进图表)。

## 四、色盲安全与双线索

- 类别区分不得只靠色相:形状 / 位置 / 直接标注是第二线索(双线索铁律的数据版)。
- 禁用红绿配对做语义对立;类别色序列优先取**明度阶梯**,再取色相环。
- 图表类别色默认从 deck colors 锚点派生(≤6 色);超过 6 类先考虑分面(small
  multiples)而不是加色。

## 五、图片式路线的披露与数据密度路由

- 图片式整页 AI 图中的图表是 **stylized**(形状示意):凡渲染风格声明「不含具体数值」
  (如 `08_图片渲染/数字仪表盘.md`),页内不得出现任何具体数字标签;数值需求改由
  页面文字区承载。
- **数据密度路由**(生成前判定,不是事后修补):
  - **≥ 6 个数据点,或含估算级数值序列** → 可编辑 / 混合路线(原生图表承载真实数值);
  - **4–5 个数据点** → 图片式可用,但形状语法强制生效;
  - **≤ 4 个巨数** → 数字海报页(图片路线最强项,配合仪式级渲染)。
- 图片路线页内出现 chart-like 形状而 approved 数据表无对应序列,visual-qa 对抗清单按
  「编造数据」打回——**编形状 = 编数据**。

## 六、学术方法图视觉语言(NeurIPS Look)

> 定位:方法架构图 / 流程图 / 机制示意图(「学术方法图」)的**图内视觉语言**,
> 与前五节的数据图表纪律正交互补——前者管「数值如何诚实呈现」,本节管
> 「方法如何被一张图讲清楚」。科研答辩风、学术五拍论证模式、`11_图表语法`
> 流程/时序图与 `07_信息图类型` 流程图/框架图在学术场景落图时先过本节。
>
> **层界声明**:本节属护栏层(三层 token 的 ① 层)文档。文中出现的少量示例
> HEX 只是「分区色怎么算」的算法示例,不受「风格不带 HEX」红线约束——该
> 红线管 ② 风格层 brief 的 `color_palette` 固有值;deck 实际用色仍走 ③ deck
> 锚点覆盖通道(`--color`/`--brand`)。

### 6.1 分区色策略

- **颜色用来分组逻辑,不是装饰**:用色划分阶段 / 环境 / 模块归属。
- **分区底色 = 浅低饱和大区底**:等效透明度 **10–15%** 的极浅色填充
  (如奶油米 `#F5F5DC`、浅冰蓝 `#E6F3FF`、薄荷 `#E0F2F1`、浅薰衣草
  `#F3E5F5`);禁止全饱和色做分区背景。
- **理论型变体**:白底 + 彩色**虚线边框**勾出分区(高对比极简,理论/优化
  类论文常用)。
- **状态用色区分组件而非组件类型**:可训练元素偏暖(红/橙/深粉),冻结/
  静态元素偏冷(灰/冰蓝/青)。
- **高饱和只留给关键事实**:正红 / 亮金**严格保留**给 Loss / GroundTruth /
  最终输出,其余元素不得抢占。

### 6.2 形状语义

| 形状 | 语义 | 备注 |
| --- | --- | --- |
| 圆角矩形(圆角 5–10px) | 过程 / 步骤 / 通用层 | 主导形状(约 8 成);「锐角给数据、圆角给过程」 |
| 圆柱 | 存储 / 数据库 / 缓存 / 记忆 | 专形专用,不做装饰 |
| 3D 立方体 / 堆叠 | 张量 / 体积 / 深度(如 B×H×W) | 混用需有理由:2D 表逻辑、3D 表张量 |
| 扁平方格 / 网格 | 矩阵 / token / 注意力图 | |
| 实线边框 | 物理组件 | |
| 虚线边框 | 逻辑阶段 / 可选路径 / 作用域 | |

- **宏-微模式**:浅色大容器表全局视图,关键模块经连线引出「放大」细节框。

### 6.3 线型语义

- **实线 = 主数据流**(前向传播 / 主链路),通常黑 / 深灰。
- **虚线 = 辅助流**:梯度更新、跳连、条件分支、Loss 回传——**同一线型
  不得混用于两种流**(歧义箭头是 Amateur 标志)。
- 网络架构图用正交折线(直角),系统逻辑 / 反馈环 / 高层数据流用曲线。
- 数学算子直接落在连线或交点上:`⊕` 加、`⊗` 拼接/乘。

### 6.4 字体分离(标签与数学严格分家)

- **模块标签 / 说明文字 = Sans**(Arial / Roboto / Helvetica 系);标题粗体、
  细节常规。
- **数学变量 = Serif Italic**(Times / LaTeX 默认):图中出现的每个变量
  (x、θ、L、S、P 等)**必须**衬线斜体,与标签字体不得混用——用衬线写
  「Encoder」标签或用 Sans 写变量都算违例。

### 6.5 领域三分支

| 领域 | 气质 | 关键元素 | 色彩 |
| --- | --- | --- | --- |
| **Agent / LLM** | 叙事、友好、可卡通 | 聊天气泡表 prompt、文档图标表检索、2D 矢量机器人 / 头像拟人化推理步 | 活泼但分区仍守 6.1 |
| **CV / 3D** | 空间、几何密集 | 视锥、光线、点云;RGB 色编码轴/通道;热力图(Viridis 系)表激活 | 按轴语义用色 |
| **理论 / 优化** | 极简、抽象、教科书 | 图节点(圆)与流形(平面/曲面)为主 | 近灰度 + **单一高亮色**(金或蓝),禁卡通元素 |

### 6.6 Amateur 反模式清单(命中即打回)

1. **全饱和背景分区**(饱和黄/蓝大底抢内容)。
2. **锐角框滥用**(数据框语义被过程框挪用)或无理由 2D/3D 混维。
3. **无语义颜色装饰**:颜色既不分区、不表状态、不标关键事实。
4. **同线型混流**:数据流与梯度流用同一种线。
5. **字体混用**:标签用衬线(显旧)、变量用 Sans。
6. **默认模板脸**:软件默认蓝橙预设 + 粗黑描边的「PPT 默认感」。
