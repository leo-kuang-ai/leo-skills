# 场景预组合预设（R-67，可选档，默认关）

> 高频场景的风格+版式集+叙事+密度**预组合**（上游：《Style管理模型》L4 预设层
> ——面向场景的预组合是对外的产品单位；leo 化为 reference 数据，非 brief，
> schema 不动）。可选档：agent 默认不启用，用户明确要"按场景直接来/用预设"
> 时才命中；命中即按 [`style-recommendation.md`](../../../../references/style-recommendation.md)
> 既有合同呈现组合与 fallback 说明。**预设缺失时按 fallback 链降级，不硬失败**
> （AE-69）：主风格缺失/被否定→按链降级风格；版式缺失→同语义区相邻 P 码替换；
> 整条预设缺失→回落常规推荐。

- **风格**：主风格名，R-66 合并后口径（变体经主风格 `aliases` 命中）。
- **版式集**：P 码真值见 `template-library/canonical/layouts/*/layout.json`
  （36 个 `layout-profile-v1` 骨架）；
  按页序为骨干，非每 deck 全用。
- **叙事参考**：`template-library/canonical/axes/argument/` 六轴之一；叙事方法论子类（12 条，如
  融资路演/事故复盘/主旨演讲）亦可作叙事取值——叙事层管「怎么说」、与六轴论证模式
  （管「怎么证」）正交可叠加，拍选配按 `template-library/canonical/axes/argument/argument-叙事拍库/body.md` 白名单。
- **密度**：low / low-medium / balanced / high（对应 canvas.density 档位语义，与 style-presets.json fields 枚举一致）。
- **fallback 链**：主风格 → 降级 1 → 降级 2（末位为内置 11 之一，永远可加载）。

呈现口径（命中预设时，与 style-recommendation.md 候选行合同兼容）：

- 直接呈现"风格 + 版式集 + 叙事 + 密度"组合与 fallback 链说明（各一行）；
  用户点名替换任一成员（换风格/换某页版式）即解除预组合，回落自由组合；
- 预设是**默认项不是确认门**：不新增交互轮次，呈现即带"回一个字母锁定/
  点名替换"的既有换法指路；
- 学术垂直既有隐性预设（答辩×科研答辩风×学术五拍）经本表显式化，行为不变。
