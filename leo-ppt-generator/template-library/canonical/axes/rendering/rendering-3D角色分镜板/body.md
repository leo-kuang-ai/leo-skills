# 图片渲染：3D角色分镜板（3d-character-storyboard）

**分类:** canonical/axes/rendering · 特色

**配对视觉风格:** —（本批新增渲染,无固定 01 配对;可直接点名,默认使用场景见 `template-library/governance/authoring/index/视觉风格配对.md` 末节）

**定位:** 白底硬黑框分镜板——Pixar 级 3D 风格化渲染 + 戏剧化饱和光,格子网格讲有个性的人物旅程

## 1. 风格段落（paste-ready，可直接用于图片生成）

> A crisp storyboard poster: white ground, hard black panel borders, and bold black typography framing premium Pixar-style 3D stylized renders. Dramatic saturated lighting gives each character or scene cinematic punch across a wide 16:9 grid. Playful yet structured — great for profiles, journeys, and step-by-step narratives with personality. Rendering guardrails: no text, no lettering, no numbers, no logos, no watermarks inside the image — any typography is applied later by the page layout, never by the image model. Compose for a 16:9 widescreen canvas (2560×1440): wide horizontal frame, not a poster column.

## 2. 线条 · 纹理 · 深度

| 维度 | 处理 |
|---|---|
| 线条质量 | Hard black panel borders, crisp 3D silhouettes |
| 纹理 | Smooth stylized 3D surfaces with cinematic lighting falloff |
| 深度 | In-panel 3D depth; grid layout stays flat and structured |
| 材质 | Pixar-grade 3D render on paper-white board |
| 情绪 | Playful, structured, dramatic, personality-forward |

> 渲染画法不写死 HEX;源卡参考色板 `#FF5A1F / #FFFFFF / #111111 / #E01E37（首色为 accent）` 与信息密度 `high` 仅作 deck `colors` 锚点缺省时的默认建议。适用场景（源自卡 tags）：人物档案 / 用户旅程 / 分步骤叙事 / 团队介绍页。
