# 医疗健康 内容规范（content_rules）

> 路由命中医疗健康行业域时强制挂接本文件；禁词力度分三档：blocked（禁用）/ rewrite（必须改写）/ annotate（必须标注）。

## 术语表

- 术语首现＝全称（缩写）：如"药物不良反应（ADR）""总缓解率（ORR）""无进展生存期（PFS）"。
- 禁用异写：＂治愈率＂以外的疗效夸大词不得作为指标名使用；批次/病例书写规范遵循临床惯例。

## 禁用与必用表述（三档力度）

**blocked（营销/推广场景禁用，《广告法》第 16 条口径）**：
- 功效保证类：治愈、治愈率、有效率、无效退款、保治愈、包治、根治
- 绝对化类：最新技术、最高科学、最先进、最有效、安全无风险、无副作用
- 背书类：患者证言、专家代言、以患者名义或形象作证明
- 比较类：与其他药品/医疗器械/医疗机构作功效比较

**rewrite（必须改写为合规表述）**：
- "效果非常好" → 引用具体研究结论并带证据元数据
- "完全安全" → "在 XX 研究中报告的不良事件谱为…"

**annotate（必须标注）**：
- 任何疗效数字必须带证据元数据（见数字标注规范）；研究阶段结论必须冠"临床研究中"

## 数字标注规范

登记表必填字段：来源 + 试验阶段（phase） + 样本量 n + 置信区间或 p 值 + 年份。
缺任一统计字段的疗效数字降 unknown；示意值禁用任何数据版式（含生存曲线/Kaplan-Meier）。

## 图表与图形惯例

- 生存曲线须标风险表（at-risk table）与随访截止；瀑布图须标最佳缓解界线
- 亚组分析森林图须标各亚组 n 与异质性检验

## 场景力度表

| 表述 | 营销/推广场景 | 学术/临床交流场景 |
|---|---|---|
| 引用已发表文献的疗效陈述 | blocked（广告场景禁疗效宣称） | annotate（须带证据元数据，不结论化） |
| "临床研究中显示 XX 改善" | annotate | annotate |
| 患者故事 | blocked（证言类） | rewrite（匿名化病例报告式表述） |

## 合规红线

- 特殊药品（麻醉/精神/毒性/放射性）做广告 → `industry_rule_violation`（blocked）
- 处方药面向大众媒体的宣传场景 → blocked（限指定专业媒体）
- 已获批上市品种宣传超出说明书范围或无广告审查批准文号 → blocked
- 伪造批注文号/注册证编号图元 → deck 级 blocked（不可逆风险）
