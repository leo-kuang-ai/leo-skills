# 排版合同

中文发布级任务在 draft/audit 输出前可选读取本文件，并可选运行 `scripts/check_layout.py`（输出为排版诊断线索，非交付门禁）。本文件是排版规约的真值源：lint 规则、eval 断言与登记判据均以本文出处为准。渠道或用户给出明确排版规范时一律从其规范。

## 1. 结构规约六条

排版动作只加标记、不改内容：允许添加标题、列表、引用、表格与行内标记，不得改写、增删或搬移正文文字。产出 markdown 遵守六条结构纪律：

1. 标题层级不跳级，全文 H1 唯一。
2. callout（连续 `> ` 行计一块）全文 ≤4。
3. 高亮标记 `==...==` 全文 ≤5。
4. 加粗每段 ≤2 对。
5. 表格 ≤4 列且必含表头。
6. 连续 3 段须有结构变化（长段接短段、列表后接散文等节奏交替）。

lint 分档（`check_layout.py` 首版口径）：第 2/3/4/5 条的可数配额为 FAIL 级；第 6 条连续同构为 WARN 级线索；第 1 条与第 5 条「表头必含」属规约条款，首版不机械判定。

来源：xiaohu-wechat-format「只加标记，不改内容」六条与密度配额（README 声明 MIT 但仓库无 LICENSE 文件，补证失败——机制吸收、文本零复制），快照 2026-08-31

## 2. px 阈值登记判据

px 是渲染产物属性，markdown 层无法验证。本节只登记出处与口径，渲染实现归渲染器与渲染测量轨道，本技能不做渲染侧强制：

- 正文 15-17px（下限 14px）、行高 ≥1.7。
- H1 ≤28px、H2 ≤22px；标题字号必须 ≥ 正文。
- 版心推导：微信正文宽约 345px，29px 中文一行仅约 11 字（345÷29≈11），长标题将占 3 行——H1 ≤28px 上限由版心换算而来，非任意值。
- 字号梯度不得倒置：h1<h2、h2<h3、h3<h4、h3<p 均判违规；豁免（如展示型主题大标题）必须显式声明，不得默认放开。
- 交叉验证：obsidian-wechat-converter 版式 token（body 16px / 行高 1.8）落在上述区间内，两源判据相容。

来源：xiaohu-wechat-format theme_lint 阈值常量与 345px 推导链（许可证缺口同第 1 节——阈值属事实性判据，机制吸收、文本重写登记）；交叉验证 obsidian-wechat-converter（MIT），快照 2026-08-31

## 3. 渲染器中立兼容条款

发布级产出必须是渲染器中立 markdown——只用标准语法表达结构与强调，交给任何成熟渲染器都能得到高质量排版：

- 链接一律用标准语法 `[文字](url)`；是否转脚注由登记渲染器决定，正文不预转换。
- 无裸 HTML 标签（`<div>`、`<span>`、`<section>`、`<table>` 等），无私有容器标记泄漏进未声明管线。
- 嵌套列表保持层级缩进；列表标记符号与序号由渲染器生成，正文不手写替代物。

自定义主题或自定义 CSS 时核对以下 CSS 安全区/禁区（登记物元信息，非本技能门禁）：

| CSS 安全区 | CSS 禁区 |
|---|---|
| 内联样式、渐变（配纯色兜底）、box-shadow、border-radius、letter-spacing、flex | position 定位、`<style>` 标签、动画、百分比偏移 |

`==高亮==` 属渲染器依赖扩展：本合同限制其数量（结构规约六条第 3 条），兼容性由登记渲染器核对后再用。

来源：md-wechat 主题文件头 CSS 合同与 renderer 行为断言（MIT）、obsidian-wechat-converter allowedCssNotes（MIT，同构口径合并为单一核对表），快照 2026-08-31

## 4. AI 排版保真条款

AI 参与版式编排时受三条保真约束：

- **封闭词表**：版式编排输出必须落进封闭、可 schema 校验的 block 词表（`additionalProperties: false` 形态），词表外字段一律拒绝；AI 只建议（recommended），运行时拍板（resolved）。
- **降级确定性**：AI 不可用或失败时必须存在无 AI 的确定性降级路径，降级发生须显式标注；降级不得静默改写正文。
- **引用不重写**：正文引用按索引对齐原文章节，不重写原文；摘录只取原文导语/观点句，不新写文案。

来源：obsidian-wechat-converter 受限词表布局 schema 与 fallback/sectionIndex 机制（MIT），快照 2026-08-31
