# 论证模式：学术五拍

学术论证。按「背景缺口 → 问题 → 方法 → 实验证据 → 结论贡献」五拍推进，每拍有明确的证据义务：缺口要有文献/事实支撑，结论要有实验数字背书。适合论文答辩、开题、组会汇报、基金申报评审、文献研读——一切面向学术委员会或同行评议的场景。

---

## 1. 论证骨架

**五拍固定，页数不均**（一拍一页或多页；第三拍占页最多——评审来这是看证据的）：

| 拍 | 角色 | 证据义务 | 页数倾向 |
|---|---|---|---|
| ① 研究背景与缺口 | 领域两三句 + 现有方法不足（不倒文献史） | 缺口须有文献/报告锚点 | 少 |
| ② 问题定义 | 待解决的核心问题与研究目的 | 问题可检验、边界清楚 | 少 |
| ③ 方法与技术路径 ⭐ | 思路、切入点、整体研究逻辑 | 能画图绝不打字：流程/架构/机制图优先于段落 | **最多** |
| ④ 实验证据 | 关键实验、头条数据、决定性图表 | **Numbers, not adjectives**：每个数字可溯源（三级标注：引用/估算/示意） | 多 |
| ⑤ 结论与贡献 | 结论 → 与自己课题/下一步的连接 | 结论不超出证据强度；贡献可枚举 | 少 |

**断言式标题**：内容页标题是完整句断言——评委三秒读出该页结论（「自注意力消除了循环瓶颈」），不是话题标签（「方法」「结果」）。标题形态按论证模式条件化的总规则见 `deck-master.md` 与 `references/visual-qa.md`「标题形态断言」判据行。

**实质纪律（Numbers, not adjectives）**：用 `h=8`、`d_model=512`、`O(n²·d)`、`28.4 BLEU`、`3.5 天 × 8 GPU` 这类具体量替代「高效 / 显著提升 / 很强」；每块至少落一个具体数字、名称或公式。**绝不编造对比**：无基线/上期/竞品数据时不造对比，按三级标注降级 `unknown` 求证。

**一页一信息**：每页只论证一件事、配一件证据（图 / 数字 / 表）；一页想讲两件事就拆页。关键词与唯一核心结论上页面，成段散文进备注。

**图优先（能画图绝不打字）**：过程、架构、因果链一律成图（流程图 / 管线 / 系统图），学术方法图的图内视觉语言按 [`00_索引/图表样式规范.md`](../00_索引/图表样式规范.md) 第六节执行；列表只留给真正清单式内容。

**推进方式**：主张 → 证据 → 含义，论文式推进；⑤拍必须回连①拍的缺口（缺口-填补闭环）。

## 2. 页面结构倾向

- 密拍（证据页：图/表/机制图）与呼吸拍（单断言 + 留白）交替，委员会才有节奏。
- 证据页以图或表为视觉中心，文字注释图，不埋图。
- 章节以分隔页或编号锚点开拍（大编号 ①–⑤ + 拍名）。
- 数据页标注来源；表格重绘胜过截图（清晰、可读、胜出格高亮）。

> 页面结构是倾向，不是坐标模板。本模式决定「每页论证什么、证据义务多重」，不决定像素位置；密度档位（组会简报 / 答辩密集）由视觉风格层承接（见 `references/styles/科研答辩风.md` 双档声明）。

## 3. 演讲备注语域

精确、学术、诚实。术语先用先定义；先说主张、再给证据、再给限定（「增益在 WMT'14 EN→DE 成立，但消融集较小」）。区分论文展示的与自己推断的；量化语言克制（「较此前最优约 +2 BLEU」，不写「好得多」）。每页备注桥接到下一拍；④⑤拍把发现回连到自己课题。预判评委可能的提问并在备注里先答。

## 4. 页面骨架示例

```
第 3 拍(方法),密:   断言标题——「注意力单独即可匹配 RNN,计算量只及其零头」
                    + 架构图居中 + 一行要点
第 4 拍(证据),表:   重绘结果表;唯一决定性数字用强调色
第 5 拍(结论),呼吸: 一句断言 + 两三行对自己课题的含义
备注:               「头条结果是 X。证据:图 N / 表 M。限定:……。对我们的工作这意味着……」
```
