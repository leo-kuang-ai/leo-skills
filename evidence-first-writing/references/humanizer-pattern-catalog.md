# Humanizer 模式目录（当前 55 类）

用于用户明确要求完整模式审查时。模式数量是当前快照而非固定事实，上游仓库的数目仍在漂移，不得把模式数或检测分数当作门禁。每项是编辑定位线索，不是 AI 作者身份判定。只有模式簇、文本位置和当前体裁共同支持时才报告；引语、标题、代码、示例、术语和作者已验证的故意表达优先保护。

## 内容 P1-P8

| ID | 检查信号 | 编辑动作 |
|---|---|---|
| P1 意义膨胀 | 普通事实被称为里程碑、转折、遗产或时代象征 | 改为具体事实，或删除重要性评论 |
| P2 知名度堆砌 | 列媒体、平台或粉丝量代替说清内容 | 保留一条能支持主张的来源，说明它说了什么 |
| P3 虚假深度分词尾句 | `highlighting`、`underscoring`、`ensuring` 等只增加姿态 | 删除尾句，或把真实信息独立成有来源句子 |
| P4 宣传腔 | 华丽形容词替代可观察事实 | 用对象、行为、结果或证据替代 |
| P5 模糊归因 | “专家认为”“研究显示”无作者或原文 | 补具体来源，或删除该 claim |
| P6 模板化挑战/展望 | “尽管挑战仍持续增长”“未来光明” | 写具体问题与事实，或删除整段 |
| P7 AI 高频词簇 | `delve`、`tapestry`、`leverage` 等在短范围聚集 | 改为平实且准确的词，单次命中不自动处理 |
| P8 回避简单系词 | 用 `serves as`、`represents`、`boasts` 替代 `is/has` | 仅在简单系词更清楚时改回 |

## 语言与风格 P9-P18

| ID | 检查信号 | 编辑动作 |
|---|---|---|
| P9 否定式排比 | 高频“不是 X，而是 Y”“不只是 X” | 直接说正面判断；真实纠偏可保留一次 |
| P10 强制三段式 | 抽象名词总被凑成三个 | 使用自然数量，或转成具体关系 |
| P11 同义词轮换 | 同一对象被连续换称，回避重复 | 选一个准确名称并重复 |
| P12 伪范围 | “从 X 到 Y”却不是连续范围 | 列出实际对象或重写关系 |
| P13 破折号过密 | 破折号承担普通解释或戏剧节奏 | 按作者样本和体裁改为句号、逗号、冒号或括号 |
| P14 格式强调过密 | 粗体、emoji 标题、分割线、表格承担表达 | 保留有语义规则的强调，删除装饰性格式 |
| P15 列表代替文章 | `**标签：** 解释` 列表本可形成论证 | 改为段落或保留真正扫描型列表 |
| P16 标题大小写模板 | 英文标题所有词首字母大写却不符合渠道规范 | 按目标格式统一，不把中文标题误报 |
| P17 排版设备痕迹 | 引号、撇号、逗号规则与作者/渠道突然不一致 | 匹配项目既有排版，不追求单一“正确”样式 |
| P18 过度正式语域 | 官样句、名词化和长前置短语替代直接表达 | 降到读者所需语域，法律/学术文本例外 |

## 填充与谨慎 P22-P30

| ID | 检查信号 | 编辑动作 |
|---|---|---|
| P22 空转短语 | `in order to`、`it is worth noting` 等不增加信息 | 删除或压缩 |
| P23 叠加限定 | `could potentially perhaps` 一类层层缓冲 | 保留唯一真实不确定性 |
| P24 通用积极结尾 | “未来可期”“迈出重要一步” | 结束在最后一个具体事实或开放问题 |
| P25 幻觉标记 | 罕见精确数字、日期、引用却无来源 | 核验、归因或删除 |
| P26 完美/错误交替 | 局部过度润色与低级错误异常混杂 | 查明来源和编辑历史，不据此判 AI |
| P27 问句标题模板 | 长文每节都用“为什么 X 很重要？” | 标题改为实际判断；教程问句可保留 |
| P28 Markdown 泄漏 | 不会渲染的 `**`、引用或代码标记进入渠道 | 按目标格式转写 |
| P29 综合概述开头 | “本文将全面探讨”“让我们深入了解” | 从真正的事实、判断或问题开始 |
| P30 句长过度均匀 | 连续多句长度/节奏相近 | 仅在簇出现时按思想需要重组，不制造随机节奏 |

## 新兴模式 P31-P43

| ID | 检查信号 | 编辑动作 |
|---|---|---|
| P31 名词短语轮换 | 人或物被连续称为多种长名词短语 | 选准确称呼并维持指代 |
| P32 协作话术泄漏 | “本文将带你”“让我带你了解”出现在成稿 | 删除协作框架，直接叙述 |
| P33 未填占位符 | `[姓名]`、`[来源]`、日期模板 | 补真实值或删除；不能猜测填充 |
| P34 模型引用标记泄漏 | `citeturn`、`oaicite`、RAG attribution 等 | 删除内部标记，必要时补真实引用 |
| P35 AI 工具 UTM | `utm_source=chatgpt` 等生成工具参数 | 去除追踪参数，保留必要业务参数 |
| P36 突然语域切换 | 同文中专业、口语、错误率突然改变 | 找出拼接段，按作者/渠道对齐 |
| P37 来源列表充当内容 | “被 A/B/C 报道”却不说明来源发现 | 选关键来源说明证据 |
| P38 段落可换序 | 相邻段互换仍不损论证 | 建立前后依赖、合并或删除 |
| P39 总结式段尾 | `Whether...`、`In summary` 反复收束 | 删除复述，结束在新信息上 |
| P40 象征性释义 | 普通事实被解释为“象征更大趋势” | 信任事实，或给出真实机制与证据 |
| P41 营销式悬念钩子 | “重点来了”“真正的转折是” | 删除吊胃口，直接给内容 |
| P42 随机行内粗体 | 没有统一语义规则的短词粗体 | 移除或建立明确强调规则 |
| P43 信息跑步机 | 多句反复改写同一点 | 运行“这句新增什么”测试，删掉复述 |

## 改写侧护栏与实证校准（来源融合 2026-08-30）

本节约束 `rewrite`/`edit` 的改写行为，并为检测权重提供实证参照。上文 P1-P55 回答「文本哪里有模板感」，本节回答「改什么、不许加什么、哪些信号值得信」。

### Never-inject 反注入护栏

改写只做减法与锐化，不做加法：删除空转、把既有主张改具体、把被埋的观点提前，属于职责；新增立场、人设或事实不属于。以下七条，源文本没有的成分一律禁止注入：

1. 假第一人称：「我的经验是」「见过太多」——源文本没有「我」，改写稿就不能有「我」；声音只能来自作者，不能来自工具。
2. 制造利害感：「在这个时代」「利害从未如此之大」——把寻常观点包进宏大紧迫感。
3. 强行反共识：「大家都说 X，但他们错了」——仅当源文本确实如此论证时合法；发明对立面就是发明主张。
4. 表演式坦白：「说实话」「重点来了」——自曝坦白的姿态而非坦白本身；改写新增一条等于同时违反两条检测规则。
5. 破折号戏剧化：改写期间不得新增制造戏剧停顿的破折号；检测侧的规则是频率上限，改写侧的规则是零新增。
6. 碎句化改造：不得把普通句子剁成碎片制造节奏；靠改写句子内容来变化句长，不靠打断句子。
7. 编造具体细节：不得补入源文本没有的数字、人名、日期、工具或机制。具体化是最诱人的修法，因为它总是更好读；编造的具体比它替代的空泛更糟。缺口标出来留给作者，不填。

逐条自检标准：改写稿中的每处信息是否来自源文本。这些约束放在改写侧而非模式目录，因为它们约束的是编辑者而非文本：作者自己写的第一人称不是 finding，工具插入的才是——差别在来源，模式看不见来源。（来源：avoid-ai-writing，快照 2026-08-30）

### 误报保护与人味保留

以下信号单独出现一律不立案；聚集才定罪：同一段落多个模式叠加才是强证据，单个破折号、单次排比、一处完美语法各自什么也证明不了。完整判断顺序见 [humanizer-patterns.md](humanizer-patterns.md)。

不单独定罪的 16 类情形：

- 专业编辑过的完美语法与一致风格——润色不等于 AI；
- 书面与口语混用——常反映写作者的领域、年龄或个人习惯；
- 平淡干巴的文章——AI 味有具体指纹，没有指纹的干巴只是干巴；
- 正式或学术词汇——词表只列过度使用的具体词，不是取缔每个正式词；
- 书信式开头结尾——问候与落款比 ChatGPT 早几个世纪；
- 孤立出现的常见连接词——「此外」「然而」堆积才是信号，单个不是；
- 单独出现的弯引号——主流编辑环境默认输出弯引号；
- 单独出现的破折号——编辑与记者常用，与公式化节奏配对才算证据；
- 单个短句强调——戏剧性碎句连续出现多个才是问题；
- 刻意的重复开头——作者靠重复建立节奏或压力，重复无增益时才处理；
- 句中「说实话」「你看」——口语正常表达，指纹是独立开场，不是词本身；
- 有用的限制与免责——范围声明、法律与安全提示、真实更正、点名回应的反方；
- 真实备选方案——设计文档、教程、论证中读者真会考虑的选项；
- 无来源主张——多数文本不附引用，缺引用不证明任何事；
- 正确而复杂的格式——可视化编辑器与模板同样产出干净排版；
- 二手文本——引语、标题、专名、示例中被讨论而非被使用的短语。

优先保留的 8 类人味信号（出现即保护，不按模板处理）：

- 难编的具体细节：真实地址、怪引语、「牙医楼上层执业的律师」这类短语；
- 未解决的矛盾心情：「大体不错，但就是不舒服，说不清为什么」；
- 年代梗：能定位到特定年份与亚文化的俚语、梗、圈内笑话；
- 模型晚一年的知识：模型知识滞后约一年以上，紧跟时效的表达是人写证据；
- 刻意的第一人称取舍：作者能解释为何保留某个删节或用词；
- 句长自然起伏：长短交替本身是证据（对照 P30）；
- 真实旁白与自我纠正：「（我总想在这儿说『几乎』，但它确实就是确定）」——模型很少打断自己；
- 2022-11-30 之前的编辑豁免：ChatGPT 公开发布前完成写作或编辑的文本，除极罕见例外不是 AI 写的。

（来源：humanizer，快照 2026-08-18）

### 可移植性测试

一句话判定填充：若一个句子原样搬到另一个人、公司或产品上也成立，它多半是填充；删除，或换成只属于当前对象的事实、机制、后果或判断。与 P43 的「这句新增什么」测试互补：前者看句子能否搬家，后者看句子是否新增信息。（来源：no-ai-slop，快照 2026-08-05）

### 实证权重注记

以下来自 avoid-ai-writing 的英文语料测量（875 个人写段落对 779 个机写段落，2022-2024 语料，文档级触发率），为权重校准提供方向：

| 类别 | 人写触发率 | 机写触发率 | lift | 校准动作 |
|---|---|---|---|---|
| 节奏均匀性 | 2.1% | 25.1% | 11.7x | 最强单信号，升权（P30） |
| 高频词表 | 8.0% | 7.4% | 0.9x | 弱信号，降权（P7） |
| 破折号 | 9.9% | 1.9% | 0.2x | 该语料中反是人写证据，降权（P13） |

三条边界：lift 接近 1 只说明该类别在这两个语料上不区分类别，不授权删除该模式——「delve 依然值得替换」，写作质量判断与作者身份判断分开；结构性信号承担主要区分力，词表类不承担；该结论来自英文语料，中文只作权重参考，不作判定依据，中文阈值需中文校准 fixture 支撑。（来源：avoid-ai-writing corpus，快照 2026-08-30）

### 结构保真与残留不增

改写前后逐项核对，以下各项的数量与内容不得变化：标题数量与层级、围栏代码块、引用块、表格、行内代码、URL、文件路径。数字缺失与大幅缩水按警告复核——数字可能是把阿拉伯数字改写为汉字，也可能是丢失事实。两个例外是本目录明示的允许改动：剥离 AI 工具 UTM 追踪参数、修正标题大小写。

残留不增：改写后的模式命中数不得高于改写前；改写可以留下模式，不能新增模式。落成另一套整齐模板的改写是失败，即使它清掉了旧命中。

该项与 `scripts/check_factual_invariants.py` 互补：结构不变量 × 事实不变量，两项都通过才算保真改写。（来源：avoid-ai-writing validate.js，快照 2026-08-30）

## 报告与退出
