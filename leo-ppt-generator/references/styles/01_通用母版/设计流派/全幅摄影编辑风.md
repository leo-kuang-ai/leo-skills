# 全幅摄影编辑风

**分类:** 01_通用母版 · 设计流派

**适用场景:**
- 建筑 / 设计 / 时尚 / 文化 / 摄影主导的长读
- 作品集选刊、空间与产品影像叙事、图文专题
- 大图说话、文字点题的杂志图片散文节奏

**三层配对建议(风格 ↔ 渲染 ↔ 调色板):**
- 视觉风格层:本风格(全幅摄影主导 + 克制文字侧 + 图注系统)。
- 渲染层:配 `企业摄影`(编辑级实拍 hero)或 `生活方式产品照`;氛围图可配 `暖光场景`。
- 调色板行为层:配 `editorial-classic`(经典编辑)或 `dark-cinematic`(影展暗场);照片承色——文字侧保持安静中性,一个克制强调只做编号/规则线/关键词。

**可参考来源:**
- GitHub: M1n-n9/academic-ppt-master · references/visual-styles/photo-editorial.md(规格书快照 2026-09-01,MIT;源规格「风格不带 HEX」,锚点取自配套 image-palettes/editorial-classic fewshot 示例)
