# Markdown 保护

保护代码围栏（含缩进与嵌套围栏）、SQL、配置、日志、命令、正则、示例输出、链接目标、引用式链接定义、裸 URL、图片路径、公式（`$...$` / `$$...$$`）、Frontmatter、标题层级、列表/引用结构、脚注标记与定义（`[^id]` 成对出现）、HTML/JSX 标签与属性和技术标识。Markdown 图片的替代文本、链接标签与图注属于面向读者的可见文本，默认译出（保持路径与语法不变）；HTML/JSX 标签的属性（含 `alt`、`title`）原样保留。默认 `code_policy: preserve`，代码块内容必须原样保留；`translate-comments` 需要语言感知的人工复核。MDX/HTML 无法可靠解析时必须显式降级。

目标侧排版规则：强调标记后紧跟中文时需保留一个空格（`**加粗** 文本`）；该规则只约束真正的强调内容，不影响 `__init__` 类裸标识符。

## 确定性脚本覆盖清单

`scripts/validate-output.mjs` 逐项比对源与译的下列保护区，任一不相等即失败：代码围栏（CommonMark 语义：0–3 空格缩进、按开栏长度配对闭合）、行内代码、行内/块级公式（LaTeX 形态）、裸 URL、引用式链接定义、行内链接目标、占位符、图片路径、HTML/JSX 标签整串、标题/列表/引用结构标记、Frontmatter；并检查目标侧强调-中文空格规则。

未脚本化、需人工核对的项目：表格对齐与单元格完整性、表格单元格内容的翻译义务、列表项的平行语法形态、脚注定义与引用的成对性（脚本只按行保护引用式定义）、链接标签与图注的译文质量、MDX 组件属性的语义正确性、代码注释在 `translate-comments` 下的语言边界。
