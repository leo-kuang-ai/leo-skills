# 通用设计规范（跨风格护栏）

> 深度内化自 `ppt-github/guizang-social-card-skill` 的设计原则，并泛化到 16:9 PPT 语境。**本规范是所有风格 brief 之上的上位约束**：任何风格（`01_/02_/03_/15_/16_` 全部 265 种 + 顶层内置）在渲染后，都必须先过本规范，再过该风格自身的 `rendering_constraints` / 身份自检。
>
> 它不替代某个风格的具体配色/版式，而是约束「什么是对的」：一套画面可以编出某风格的样子，却仍是「generic template 套了层皮」——本规范就是用来抓出这种假风格。

## 一、排印铁律

**1. 越大越轻(the larger, the lighter)——按三档表情执行。** 大方向不变:超大标题用轻字重,小字号标签用重字重。字重区间分三档,风格 brief 声明其一,**同一 deck 不跨档,规范校验档内一致**:

| 表情档 | 字重区间 | 适用风格系 | 补偿约束 |
| --- | --- | --- | --- |
| **Whisper** | 200–400 | 编辑部/水墨/极简/静奢 | 无(默认最安全) |
| **Speak** | 400–600 | 咨询/科技/商务/党政正文 | 大标题 ≤600 |
| **Shout** | 700–900 | 波普/新粗野/大字报/党政标题 | 仅标题层;优先负形/描边而非实心粗体;全 deck ≤2 页;逐处在母版登记 |

Whisper/Speak 档大标题禁 700+;Shout 档的 700+ 是**登记制例外**——例外要付代价,且例外可数。反例依旧是:`<h1 style="font-weight:800">` 的无声明巨大粗体。

**2. 中文标题先缩文案,再缩字号。** 中文视觉密度高。标题过长时:先砍字、再降号;**绝不**靠把正文字号压到不可读来「挤下」标题。字号下限**双口径**(同一比例,两个画布基准):

| 元素 | 1920×1080 HTML 口径 | 2560×1440 生图口径 |
| --- | --- | --- |
| 正文 | ≥18px | ≥32px |
| 卡片/图注/caption | ≥16px | ≥28px |
| meta/kicker/图表标签 | ≥14px | ≥24px |

(密度表格页可放宽至 24px@2560 并在母版标注;换算依据见 `版心Canon.md` 字阶表。)

> **与版心 Canon 的两层关系**：本表 32px@2560 是**绝对红线**（任何画面不得低于）；
> `版心Canon.md` body 档 1.7–2.2vw（≥44px@2560）是**新写版式/风格的刻度下限**——
> 新写场景必须从 Canon 字阶表取值（≥44px）；存量风格按红线兼容，逐步向刻度收敛。

**换算判据（成文口径）**：1920px↔13.33in 画布下 1pt = 2px（18px = 9pt、24px = 12pt）；
**direct-editable / PPT 原生路线以 pt 口径执行**——正文 ≥14pt（投屏建议 14–24pt），因为可编辑
PPT 的字号是绝对单位，与像素画布无关；图片路线按上表像素口径执行。判定过程与结论随交付
记入 CHANGELOG，可复核。

**3. 语义硬断行。** 中文长标题在换行时按语义缝断(主谓/动宾/并列),不靠 CJK 自动换行——自动换行常产生尴尬断点。

**4. 混排克制。** 中文内容大标题宁纯中文;英文只在承载标题(品牌名/术语)时才混入。

**5. CJK 字距为正。** 中文正值字距为基准(+.03~.04em 常用);负字距(-.05em 等)仅允许拉丁字系。中文压负字距会糊,同库文件不得自相矛盾。

**6. 身份字体声明。** 每份视觉风格 brief 必须声明它「拥有」的字族用法:中文主字族(思源黑体/MiSans/HarmonyOS Sans/宋体系等具体到族)+ 英文搭配 + 字重区间 + 一句气质理由;**风格间不得共用同一声明**。"clean sans-serif" 这类零信息描述不允许出现在 typography 字段。

**6a. 字体 → 生图模型视觉描述语（图片路线追加措辞）。** 扩散模型不认识字族名;
`typography` 字段经 `style render` 机器直注进每页 prompt 时,brief 写法约定在字族名后
追加一小段**视觉描述语**,让生图模型按字形气质渲染(可编辑路线照常消费字族名,本层
对其无影响)。两条纪律:① 描述语**不含字重词**——字重永远由三档表情声明(§一.1)
映射(light/regular/bold),防止「越大越轻」被 bold 措辞诱导破档;② 描述语控制在一
短语内(字族锚截断 80 字符)。子档对照(来源 baoyu-skills dimensions/typography.md
Font Rendering Instructions 表,MIT 快照 6b7a2e4 2026-07-03,按全局栈三系改写+扩写):

| 子档(对接全局栈) | 字族气质描述语(无字重词) |
| --- | --- |
| 黑体系 · geometric | geometric sans-serif with perfect circular O shapes, uniform stroke width |
| 黑体系 · humanist | humanist sans-serif with open apertures, slightly warm details |
| 黑体系 · 等宽子档(仅 labels/代码/数据位) | precise sans-serif with monospace numerals, 0/O and 1/l clearly distinguishable |
| 衬线系 · editorial | high-contrast serif with sharp bracketed serifs, magazine display quality |
| 衬线系 · quiet/classic | quiet classic serif with modest contrast, catalogue gravitas |
| 手写系 · handwritten | hand-lettered marker strokes, letters that look drawn not typed, imperfect baseline |

写法示例:`"title": "思源黑体 · geometric 档(geometric sans-serif, circular O shapes)"`。
落位节奏:按「点名命中/触发渲染修订时顺手补」渐进,不专项批量重写(同 negative_prompt
渐进补齐先例)。

**7. 全局字体栈（fallback 阶梯）。** 身份字体声明落不到位或环境缺字体时,按全局栈回落,
风格文件只允许在栈内换族、不得绕过字重与下限:

| 档 | 中文主字族 | 西文搭配 | 用途 |
| --- | --- | --- | --- |
| 黑体系（默认） | 思源黑体 / Noto Sans SC → MiSans → HarmonyOS Sans → 苹方 → 系统黑体 | Inter → Helvetica Neue → Arial | 科技/商务/数据/教学 |
| 衬线系 | 思源宋体 / Noto Serif SC → 宋体（Songti SC）→ 系统宋体 | Georgia → Times New Roman | 人文/学术/杂志/水墨 |
| 手写系 | 楷体 / 手写体（马克笔体等,以 brief 身份声明为准）→ 霞鹜文楷 / LXGW WenKai（楷体气质备选,与手绘白板风身份声明对齐） | Caveat → 系统手写 | 白板/手绘/温暖手工 |

> 霞鹜文楷（LXGW WenKai）为可编辑/render lane 备选（OFL 可得，`assets/render-fonts/`
> 收录时需同步登记 NOTICE）；图片路线注入不受本行影响（字体渲染措辞见 §6a）。

**8. 行高阶梯。** 行高是护栏不是自由值:标题 1.1–1.2;正文 1.4–1.6(中文取上限);caption/meta
1.4–1.5;大字海报（display）1.05–1.15 且必须配双约束限高。同页同类元素行高一致。

## 二、版式铁律

**1. 内容形状决定版式（content shape decides layout）。** 永远不要先选一个漂亮版式、再往里面塞内容。先判定这页的语义角色（封面/论点/证据/对比/结语），再定版式。

**2. 每页一个焦点。** 一页只能有一个视觉重心（大标题、主图、或核心结构图）。多焦点 = 无焦点。

**3. 不欠填——按风格分档。** 活跃构图占页面的目标比例分三档:极简类风格 40–60%(必须有锚点:kicker/出处行/细线/元信息,否则读作「漏了元素」);默认风格 ~78%;台账/账单类信息密集页可到 90%(仍守版心与安全区)。横向 16:9 的「欠填」表现为右侧/下方大片空白;封面、金句页可以留白,但同样必须有锚点。

**4. 页面节奏。** 一套 deck 至少 5 种页面形态;「标题 + 导语 + 3 行」这种模板页在一个 deck 里连续出现不超过两次。英雄页（大图/大标题）与安静页（台账/清单）交替。**多样性计数豁免陈述页/氛围页**——这两类页型的力量来自重复的安静,不参与「5 种形态」计数,但仍不得连续 3 页同主体结构。

**5. 版式是「设计过的」，不是「整理过的」。** 用尺度对比、非对称、精确边距、微标签制造设计价值；不要让次要母题（页脚、图标、色条）变成反复出现的「模板骨架」。版面数值(边距/栏/gutter/字阶)一律引用 [`版心Canon.md`](版心Canon.md) token。

**6. 页面密度禅档位。** 要点数上限按页面角色分档,不搞一刀切:

| 页面角色 | 要点上限 |
| --- | --- |
| 陈述/氛围/金句页 | 0–1 条(零要点合法,视觉行写「全幅图 + 一句断言」) |
| 论点/证据/方案页 | ≤3 条 |
| 台账/账单/附录页 | ≤6 条(只有台账配 6) |

母版生成时打档位标签,视觉门按档位审;全页要素总数(卡片+图标+图表块)一并受档位约束。
**每页正文字数上限**:论点/证据/方案页正文合计 ≤80 字(中文,含标点;图表口径说明与出处行
不计);陈述/氛围页 ≤20 字;台账/附录页不受此限但仍受版心约束。超限先删字,不缩字号。
富文本版式(P13 双列段落/P18 论点段落等)按要点行计:每要点一行 ≤40 字,同页合计仍受 80 字约束。

**7. 仪式页配额。** 全幅氛围页与仪式页(P36 类)每 deck ≤2 页;与 Shout 字重页配额(§一.1)
各自独立计数。氛围页的力量来自稀缺,连续两页氛围 = 没有氛围。

## 三、配色铁律

**1. 强调色三制式。** 风格 brief 声明配色制式之一,**档内执行、不跨制式混用**:

| 制式 | 规则 | 适用 |
| --- | --- | --- |
| **mono-accent**(默认) | 一套 deck 只用一个强调色,不混蓝黄绿橙;强调用于「关键点/结论/决策点」,不用于大面积装饰 | 咨询/科技/极简/大多数风格 |
| **dual** | 双色调系统(如党政红金、深蓝+暖橙);两色有主次,强调仍是「主强调色 + 语义对立色」 | 党政/对比叙事 |
| **poly-pop** | ≤4 色固定搭配(孟菲斯糖果色/蒸汽波三色);此制式下「强调 = 画面中最大对比对」,不再要求单色 | 波普/孟菲斯/蒸汽波/新粗野 |

**2. 60-30-10。** 主色 60%（背景/纸面）、辅色 30%（结构/卡片）、强调 10%（关键点）。违反即杂;poly-pop 制式下改为「底色 60 / 结构 30 / 表现 10」。

**3. 强调色是信号不是涂色。** mono 制式下,若整页到处是强调色，强调就失效;一个强调点足以。accent 一经选定,在 run 级锁定并写入 deck_spec 元数据(可复现),不逐页漂移。

**4. 对比度。** 正文与背景 ≥ 4.5:1;蓝字压黑图/深色照片是明确错误。大字(≥24pt)与图形边界 ≥3:1(非文本对比),关键信息必须有颜色之外的第二个线索(文字/形状/位置)——**双重编码是铁律,不是建议**。

## 四、图像铁律

**1. 图是证据或氛围，不是装饰。** 每张图都要回答「它支撑什么观点」；答不上的图删掉。禁止装饰性 SVG 圆、散点、光斑、bokeh、贴纸、假图解、装饰渐变。

**1a. 图像来源三级标注（AI 时代新增）。** 页面用图在母版视觉行标注来源级:

| 来源级 | 含义 | 用途边界 |
| --- | --- | --- |
| **实拍** | 用户提供的真实照片/截图 | 可进「证据」槽 |
| **生成-氛围** | AI 生成,承载情绪/场景 | 禁入「证据」槽;不得呈现为纪实影像 |
| **生成-示意** | AI 生成,示意概念/机制 | 必须可被辨识为示意(插画/风格化),配「示意」标注 |

AI 生成写实照片**冒充实拍**进入证据槽 = 交付事故,visual-qa 按违禁项打回。

**2. 全幅图先过两测试。** 文字要压在整幅图上时，图必须先过：
- **安静区测试**：至少一个 ≥30% 画面的带是低细节/低对比/均匀的（失焦、阴影、雾、静水、纯天）——标题落这里。
- **光线测试**：图带氛围/克制光（阴天、晨雾、黄金时刻、胶片柔光），拒绝高饱和正午、机顶闪光、游客自拍。
任一不过 → 换图或改分栏（图放进框），**不要用遮罩硬修**。

**3. 主体避让（subject map）。** 图有主体（脸/手/产品/峰）时，文字绝不压主体。放字前先「读图」：主体焦点在哪、轮廓边界在哪、最大开放区在哪。文字放安全区，优先级：主体上+下 > 单侧 > 对角。**绝不把大标题切过人脸。**

**4. 遮罩只用「局部、取图像色」的柔 tint。** 对比度不够时，只在标题区加 `radial-gradient` 单侧渐隐，色取图内深色（森林→深苔、黄昏→茶玫、雪→冷灰蓝），峰值 alpha 0.15–0.30。禁用整幅纵向黑渐变、纯黑遮罩、平黑/白板、`opacity:.6` 整图。

**5. 截图是证据就给它足够大。** UI/代码/图表截图用 contain（保留像素），占页高 45–65%，上方只一句，底部说明带；不要缩到看不清。

## 五、身份自检（每个风格渲染后必答）

渲染完任何一张，先问这 6 问，任一条「否」就打回：

1. **去掉装饰还能成立吗？** 抽掉色块/图标/线后，核心结构与逻辑是否仍清晰？
2. **一眼能看到「结构」和「为什么」吗？** 画面是否只是把内容摆上去，还是有一个可辨识的图形想法？
3. **字重对吗？** 大标题是否偏轻、小标签是否偏重？有没有 700+ 的大标题？
4. **强调色克制吗？** 是否只有一个强调色、且只落在关键点？
5. **图是证据吗？** 每张图都支撑观点吗？有没有装饰性杂图？
6. **像该风格吗，还是像「模板套了层皮」？** 换成另一个风格名，这页是否还「说得过去」？（说不过去 = 没有风格身份）

## 六、反模式 / 坏味道清单（交付前自查）

出现任一，先改再交付：

- 页面像「generic 模板 + 文章粘贴进去」。
- 多页下部/右侧大片空白。
- 装饰形状不解释任何东西;**任何高度/长度不由数据授权的 bar/塔/竖线**(编形状 = 编数据,判据见 [`图表样式规范.md`](图表样式规范.md))。
- 估算/示意数值进了量化图形(KPI 卡/塔/条/饼)且没有形状语法(纹理/虚线 + 「~」前缀)。
- AI 生成写实图冒充实拍证据;生成图未标「生成-氛围 / 生成-示意」。
- 中文用负字距;同库两个文件字距方向相反。
- 截图小到看不清。
- 页间边距不一致。
- 蓝字压黑图/深色照片、对比不足;关键信息只靠颜色区分(无双线索)。
- 一个 1:1/方图是把 21:9 封面生硬裁剪出来的。
- emoji、假数据、假百分比、Lorem 占位、虚构 logo/水印/评级（豁免：brief 明示登记的降级方案中的 emoji 点缀除外，如玩味手绘极简风/不羁玩梗流行风的"emoji 替真插画"降级；豁免必须写在 brief 的 visual_elements/layout_patterns 里，不得临场自创）。
- 同风格内混用两种强调色（mono 制式）、或混用圆角与直角卡片。
- typography 只写 "clean sans-serif" 而无身份字体声明。

## 七、与风格 brief 的关系

- 本规范是**公共上层**；每个风格 brief 的 `color_palette` / `typography` / `layout_patterns` / `rendering_constraints` 是该风格的具体落地。
- 冲突时：**本规范的排印/图像/身份铁律优先**（它们决定「对不对」），风格的配色/版式决定「像不像」。
- 风格 brief 里已写身份自检/反模式的（如两个 Guizang 权威版），与本规范一致，不重复执行两套——本规范是它们的上位提炼。

## 八、版式匹配与对齐 P0（内化自 guizang-ppt-skill）

> 排印/配色/图像之外，**版式层**还有两条独立的上位铁律（详见 `12_版式库/00_选版式P0原则.md` 与 `12_版式库/01_常犯错误.md`）。

### 1. 内容类型必须匹配版式（最常踩雷）

版式承载内容的「形状」是固定的——**先看内容，再选版式，绝不先选版式再编内容硬塞**。

| 内容类型 | 用 | 严禁 |
|---|---|---|
| 有真实量化数据 | 数据版式（KPI塔 / H-Bar / Ledger / Tech Spec） | 无数据版式（Statement / 六格 / 三力卡） |
| 无数据，纯定性论断 | 陈述 / 宣言 / 三力卡 | ⚠️ 数据版式（编造数据会被识破） |
| 闭环结构 | 循环图 | 横向流程（线性 ≠ 闭环） |
| Before/After | 双轨对照（必须 2 项） | |
| 三层嵌套 | 系统图 | |

经典雷区：用 H-Bar 展示「三个概念性能力」并编造 96/88/78 百分比 → 数据不可信，版式滥用。

### 2. 版式对齐法则（每页必查）

- 不二次叠加水平 padding（基础层已带 padding，主体再叠 = 双倍内缩、左右不齐）。
- kicker 必须在大标题**上方**（上下结构，非左右挤）。
- 大字号双约束限高 `min(Xvw, Yvh)`，其中 Y ≥ X × 1.6。
- 子元素间距用网格 `gap`，不用 margin/padding 堆叠。
- 底部分页安全区：主内容最低处不触及 nav，留 ≥3vh 呼吸。
- 版式多样性：7-8 页 deck 至少 6 种不同版式，不连续 3 页同结构。

## 九、deck 级动效规范（转场与时长预算）

版式内动效 recipe 归 `12_版式库/` 各版式;本节管 **deck 级**——翻页转场、总时长与降级:

1. **转场白名单**:全 deck 统一一种转场,只允许 `fade`（可编辑路线另可用 `morph`,且
   仅用于前后页存在同名对象的连续页）;禁止弹跳/旋转/棋盘等表演型转场。
2. **时长预算**:单页内动效合计 ≤1.5s;整 deck 动效时间预算 = 页数 × 0.5s 封顶;逐页
   recipe 的毫秒参数（如 P11 220ms/节点）计入本预算。存量 recipe 若因上限件数略超
   （如 P11 七节点 1.54s）视为登记豁免;新写版式不得新增超限。
3. **每个动效必须回答「引导什么注意力」**:说不出注意对象的动效删除;这是版式 recipe
   语义化原则在 deck 级的重申。
4. **降级策略**:导出静态 PPTX/PDF 时动效语义须等价（信息不依赖动效到达——分步揭示
   的内容在静态导出中必须全部在场）;可编辑路线用 PowerPoint 原生 animation/morph 实现。
5. **图片式路线零内动效**:整页一张图的路线无页内动效能力,动效语义只存在于转场与
   讲演;交付说明须注明此局限。
