# 版式：P24 · Number Hero · 单一数字冲击页

**分类:** 12_版式库

**用途:** 一个压倒性数字的安静大字页——单一巨数 + 一句话 + 单位/口径注脚。

**适用内容类型:** 恰好 1 个引用级强数字（必须带登记表行与口径注脚）。无数字或 >1 个数字 → 改用 P4/P6。每章至多一页。

**骨架:** 全幅留白 + 中央单一巨数（≥ 12vw）+ 数字下一句话（≤ 14 字）+ 页脚单位/口径/来源小字。

**关键类:** `.number-hero` `.hero-caption`

**动效 recipe:** `hero-count` — 数字从 0 计数滚动到位（数值真实，非装饰）。

> 口径注脚是本版式的合同部分：无注脚即失败（数字登记表纪律）。
