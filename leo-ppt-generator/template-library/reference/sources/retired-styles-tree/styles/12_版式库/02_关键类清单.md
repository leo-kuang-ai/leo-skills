# 关键类清单(12_版式库 · 单一真值)

> 定位:版式骨架「**关键类**」字段引用的 CSS 类,以本文为**唯一定义真值**——未在本表
> 登记的类名不得写入任何版式的「关键类」字段;新增类必须先在本表登记定义再被引用。
> 来源:大师评审团 R12 决议(Vignelli:一个 deck 的所有页面应像同一个人做的;共享
> 结构语言从共享类开始)。盒模型数值一律引用 [`00_索引/版心Canon.md`](../00_索引/版心Canon.md)。

## 一、共享基础类(跨版式复用,不得局部改义)

| 类 | 定义 | 使用版式 |
| --- | --- | --- |
| `.card-fill` | 灰底直角卡片底(无圆角/无描边/无阴影);填充类型互斥:ink / accent / fill / outlined 四选一 | P5 / P4 / P13 / P15 / P16 |
| `.ascii-bg` | 字符打点纹理层(IIFE 自动启动,不依赖手动调用) | P1 / P9 |
| `.slide.split` | 左右分屏页面骨架(两半各自垂直居中) | P8 / P9 |
| `.half.b-accent` | 分屏的强调色半屏(accent 只许一侧) | P9 |
| `.vrule` | 垂直 hairline 分隔(scaleY 拉开动画载体) | P8 |

## 三、纪律

1. 「关键类」字段只写本表登记过的类;新类先登记(附语义与盒模型一句话)再引用。
2. 共享类不得在单个版式里被局部重定义;需要变体时新增登记(如 `.brief-card.is-accent`)。
3. 数值(字号/边距/gutter/hairline)一律引用版心 Canon token,不在类描述里自造。
