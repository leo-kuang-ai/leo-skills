# 叙事方法论：学术研究报告（academic-research）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../../../references/rst-paging.md`](../../../../../references/rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../argument-叙事拍库/body.md`](../argument-叙事拍库/body.md)）。

一句话：按研究受众期待的**建构顺序**立论——问题、已有工作、方法、结果、解释——
让结论始终可回溯到证据，且局限保持可见。

## 1. 适用场景

研究汇报、学术报告、论文宣讲、评审答辩的**叙事组织**（面向同行评议受众的
内容序列与节奏）。凡「结论先于方法就无法被评判」的场合。

## 2. 页序骨架

节位序列（非页数模板——页数按材料量与禅档位定；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 开题 | 研究问题（Research question） | 问题是什么、为何重要、为何仍开放 |
| 定位 | 已有工作定位（Prior work positioning） | 相对已知知识的站位，不倒文献史 |
| 主张 | 贡献声明（Contribution claim） | 本文主张的可枚举贡献 |
| 路径 | 方法与材料（Approach / Data and materials） | 可复现到可评判的程度 |
| 发现 | 结果（Result） | 按观察呈现，不按期望 |
| 对照 | 比较与消融（Comparison and ablation） | 与基线/消融的直接对照 |
| 解读 | 解释（Interpretation） | 结果意味着什么、不意味着什么 |
| 边界 | 局限与威胁（Limitation and threats） | 效度边界留在宣讲内，不只留在论文里 |
| 收束 | 结论与后续（Conclusion and future work） | 回连问题与下一步 |
| 附录 | 补充细节（Supplementary detail） | 供质询的高密度材料 |

## 3. 节奏要点

- 时限紧**压缩中段（方法/结果）也不倒置顺序**——受众必须能从结论回溯到证据。
- 探索性、确证性、阴性结果**各自保持诚实形态**，不用同一模板硬套。
- 一页一发现/一方法组件/一对照；图与其支撑的主张同页。
- 观察与推断的措辞全程可区分，不让一个漂移进另一个。

## 4. 与论证模式轴的关系（正交声明）

- 本条管研究叙事的**页序与节奏**；证据义务与论证骨架由论证模式承接——
  推荐配对：**学术五拍**（五拍证据义务、Numbers not adjectives、缺口-填补闭环）。
  源声明 Preferred Mode: custom（instructional + pyramid）→ leo 侧亦可配
  教学分解（概念先行时）与结论先行金字塔（评审备忘式汇报）。
- 不重叠：学术五拍定「每拍论证什么、证据多重」；本条定「按建构顺序怎么讲、
  局限与阴性结果放在哪、节奏如何让回溯成立」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：方法（method）、结果（results）、图示注解（annotated）、参考文献（references）
- 节奏签名：先方法后结果（method-then-results）、图表+解读（chart-plus-interpretation）
