# 教育学术 内容规范（content_rules）

> 路由命中教育学术行业域时强制挂接本文件。

## 术语表

- 术语首现＝全称（缩写）；全 deck 缩写一致（由术语表机制承载）。
- 学科惯用计量表述保留原文（如 effect size 报告惯例）。

## 禁用与必用表述

- rewrite：未发表数据区分两式标注——"个人通信（经作者许可）"与"待刊（in press，embargo 已确认解除）"
- annotate：引用必带来源行（作者. 机构/期刊. 年份）；统计结论必带检验语境

## 数字标注规范

登记表必填字段：来源 + 样本量 n + 误差类型（SD/SE/CI） + 显著性（p 或区间） + 年份。
缺统计字段的数字降 unknown；统计图（散点/箱线/森林图）缺误差或样本量标注则降级示意版式。

## 图表与图形惯例

- 统计图带误差线与 n 标注位；坐标轴含单位
- 引用角标（上标编号）与文献页一一对应

## 场景力度表

| 表述 | 课堂/组会 | 正式发表/答辩 |
|---|---|---|
| 初步结果 | annotate | annotate + "初步"冠词 |
| 待刊数据 | annotate（in press） | blocked（embargo 未解除时） |

## 合规红线

- 违反期刊 embargo 的待刊数据披露 → blocked
- 编造文献/注册号 → 按不可杜撰红线 blocked
