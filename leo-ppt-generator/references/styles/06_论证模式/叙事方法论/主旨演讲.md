# 叙事方法论：主旨演讲（narrative-keynote）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../rst-paging.md`](../../../rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../叙事拍库.md`](../叙事拍库.md)）。

一句话：故事驱动的演讲叙事——用一个人们认得的世界开场，用可感的张力扰动它，
跟着转折走，落在它此刻对听众的要求上；**一个思想统辖全场**，页面服务演讲者
而非替代演讲者。

## 1. 适用场景

大会 keynote、愿景演讲、思想领导力场次、文化与变革沟通——一切
「幻灯片支撑演讲者、而非独立成立」的 spoken talk。

## 2. 页序骨架

节位序列（长度随戏剧重量而非节位对称；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 开场 | 开场画面（Opening image） | 先把听众放进一个具体情境，再解释任何事 |
| 共识 | 被认出的世界（Recognized world） | 建立将要被扰动的共同现实（听众可自查的条件） |
| 张力 | 张力（Tension） | 让问题被感到而非被描述（代价/矛盾/损失的真实尺度） |
| 证据 | 证据拍（Evidence beat） | 证明张力真实且普遍（一个数字+来源/范围/期间，非仪表盘） |
| 人性 | 人性细节（Human detail） | 用一个具体的人/时刻让抽象落地（合成/示意须标注） |
| 转折 | 转折（Turn） | 全场存在的理解转变——最克制的一页，一句+最大留白 |
| 再框 | 再框（Reframe） | 转折后熟悉世界的样子（用引入时的同词回访） |
| 含义 | 含义（Implication） | 对在场的人意味着什么（挂到他们真正可控的决策/行为） |
| 出口 | 收尾嘱托（Closing charge） | 带出会场的一个行动/承诺（对难度诚实；不复述刚讲过的） |
| 附录 | 参考与出处（Reference and attribution） | 引用/图片来源，排在叙事之后，密而静 |

## 3. 节奏要点

- **一页一拍、一个主导元素**（一张图/一句陈述/一个数字）；两秒可读，
  听众随即回到演讲者。
- 每拍制造下一拍的需要；绝不让叙事惯性把信念升格为事实——观察、解读、
  信念措辞可辨。
- 转折页全场最克制；再框镜像早前页面的构图，让变化被感到而非被解释。
- 不把一拍拆到需要听众重组的多页；节拍已过不滞留画面。

## 4. 与论证模式轴的关系（正交声明）

- 本条管演讲叙事的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **故事弧**（源声明 Preferred Mode: narrative；情境→张力→解决的弧线与悬念），
  证据拍可辅**学术五拍**的 Numbers-not-adjectives 纪律（来源/范围/期间）。
- 不重叠：故事弧定「怎么证——情绪弧线说服的论证形态」；本条定「张力于转折
  的演讲页序、一页一拍节奏与口语叙事的措辞纪律」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：作者声音（voice）、图示注解（annotated）、田野发现（field-findings）
- 节奏签名：文章式跨页+停顿（essay-spread-with-pauses）、
  人尺度叙事（human-scale-narrative）
