# 专家报告 S3 · MECE（能力空间覆盖）

- 评审对象：PRD v1.2 · 方法论：MECE（能力空间定义 + 重叠/缺口检查）
- 日期：2026-09-11 · 独立审查（不重复上轮 47 findings）

## 能力空间与投影

轴 A 关切域{产物质量（文字/视觉/数据图表/内容讲稿/可达性）、过程效率（成本/时延/韧性）、人的决策（证据/负担）、数据飞轮（测量/学习）} × 轴 B 职责层{确定性/AI 判断/人决策} × 切片 C 生命周期{run 前/中/后/跨 run}。

三条结构性判读：①**AI 判断列活跃条目为零**——本批唯一真 AI 判断条目 R-83 已暂缓，三层原则只建了两足；②图表相关三格子（数据图表×AI 判断/确定性建设/人决策）全部无条目；③飞轮只有测量半环有主，学习半环无主。生命周期：run 中与跨 run 是两条空带。

## Findings

- **F3-1 [高] 缺口**：v1.2 用户点名的"AI 自行结合材料思考生成图表"落在（数据图表×AI 判断）格子却无 accountable 条目；"由内容质量 evals 覆盖"是维护手段不是能力建设——既无存量用例盘点证明已覆盖，也无条目把"新增图表构思 evals 用例集"登记为交付物。→ 新增轻量条目 R-84（P1）："为 deck-master 图表容器声明建立可评测质量基线——交付图表构思 evals 用例集（图型选择/数据三级标注引用/叙事匹配+判读协议），以 R-77 图表页 QA 漂移数据驱动迭代"；最低限度也要把用例集登记为 R-74 回归的伴随交付物。
- **F3-2 [中] 缺口**：数据飞轮学习半环无主——测量产出无承诺流程转化为行动。→ R-77 验收加轻量过程承诺："建议输出"处置决定（采纳/搁置+理由）按固定节奏留痕归档；全局非目标显式记录"自动闭环非本批目标"。
- **F3-3 [中] 重叠**：R-70/R-73 同关切未划界——正确分界：composite 文字层走构造性逐字断言，OCR 门只管 image lane 整页生成页；对确定性文字层跑 OCR 纯增误报零收益；对冲关系（R-70 降级则 R-73 价值上升）未成文。→ R-73 补 lane 适用性划分；排序节补对冲说明。
- **F3-4 [中] 边界**：R-72 移除无重启条件记录（与 R-83 标准不对称）；v1.1 裁定 8 的证据先决（R-77 lane 占比+图表页 QA 漂移率）随验收"作废"，重启证据无处安放；图表三路径语义（editable 形状重建/render mermaid/图像 lane）统一无人认领。→ R-72 补三行式重启条件（判据+前置+保留物）；语义统一并入 R-74 或 R-84。
- **F3-5 [中] 缺口**：跨 run 连续性（交付物迭代 v2）为空——R-72 移除带走"数据更新不重出图"收益，端到端迭代体验无人负责。→ 显式非目标+R-77 加"同项目重复 run 占比/母版复用率"零成本指标，数据成立再立项。
- **F3-6 [低]**：mid-run backend 切换的混合 provenance 披露口径未声明。→ R-74 非目标扩句；R-77 可加"中断 run 恢复成功率"观察指标。
- **F3-7 [低]**：mid-run 用户介入无格无声明。→ 显式非目标一句（走既有 post-confirm/artifact revision 链路）；R-77 观察用户主动打断频次。
- **F3-8 [低]**：R-74 输入的"页型全集"在 R-70 分阶段期有两态，未锁定。→ R-74 依赖注明以 R-70 全面转正门后全集为输入；规则表按封闭枚举设计。
- **F3-9 [低]**：呈现类验收断言三处各自为政。→ R-76 拥有"怎么呈现"，R-74/75 只断言内容字段存在与正确。
- **F3-10 [低]**：R-78"alt 清单"与 R-79"alt 清单"术语撞名指代不同。→ R-78 改"拼图及其图注说明"。
- **F3-11 [低]**：R-71 风险页标注与 R-75 共用容量预检基建，此消彼长未声明。→ R-75 注剩余定位；建议器输出兼作风险页"为何 risky"解释（一份基建两用）。

## 总体结论

**相互独立大体达标**（v1.1 底子好，残留 3 处未划界为句子级修补）；**完全穷尽不达标且空缺集中**：AI 判断层整列为零、run 中/跨 run 空带、飞轮学习半环无主；最尖是 F3-1（用户点名方向落在唯一无条目的格子）。修补成本低：1 条轻量新条目+数句并入+3 条显式非目标/重启条件，不动摇排序与红线。

## 一句话立场

确定性与人决策两根柱子扎实，但 v1.2 把用户点名的图表能力放进了全空间唯一没有条目的格子——补 R-84、留 R-72 重启条件、空格封边，MECE 即闭合。
