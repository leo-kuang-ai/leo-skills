# 版式：P33 · Team Grid · 团队网格

**分类:** 12_版式库（人物结构版式）

**用途:** 团队介绍页 / 顾问阵容 / 项目组展示 / 致谢名单。

**适用内容类型:** **3–8 位人物**(每人 = 头像 + 姓名 + 角色 + 一句话背景,四件套缺一不可)。>8 人改用两页或 P15(纯名单);只有创始人 1–2 人的深度介绍改用 P30 Swiss Image Split(人物照 + 段落)。**头像必须有真实图源**(个人照/官网截图);无图源时用姓氏首字字母块(accent 单色),**禁止占位灰图与 AI 生成人像冒充实拍**。

**骨架:** 顶部页标题(h1 8.4vw)+ 可选一行团队说明 / 下方 3–4 列网格(头像块 12vw × 12vw,直角或全圆二选一,全页统一)/ 每卡:头像 + 姓名(h3 4.0vw)+ 角色(meta 1.2vw,accent 或灰)+ 一句话背景(caption 1.2vw)/ 卡片间距 grid gap 与版心 gutter 一致。

**关键类:** `.team-grid` `.team-card` `.avatar-block` `.avatar-fallback`

**动效 recipe:** `team-reveal` — 卡片按行 stagger 入场(120ms 错开),头像 scale 0.96→1,文字 fade

> 版式是「页级可粘贴结构」，约束内容类型匹配（见 `选版式P0原则.md`）。人物信息以公开资料为准,头衔不得杜撰;AI 生成头像须按通用设计规范「AI 图像三级标注」声明。数值呈现遵守 `00_索引/图表样式规范.md`。
