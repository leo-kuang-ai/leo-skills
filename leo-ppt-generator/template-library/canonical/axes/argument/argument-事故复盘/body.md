# 叙事方法论：事故复盘（incident-postmortem）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../../../references/rst-paging.md`](../../../../../references/rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../argument-叙事拍库/body.md`](../argument-叙事拍库/body.md)）。

一句话：**无责（blameless）**的事故评审叙事——重建时间线、把促成因素与追责分开、
落到可验证的行动承诺，让组织从失败中学到东西而陈述不偏向任何人。

## 1. 适用场景

生产事故复盘、故障报告、质量与安全事故调查、安全事件 debrief、可靠性回顾。

## 2. 页序骨架

节位序列（非页数模板——页数按严重度定，深度随严重度而非固定模板；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 摘要 | 事故概要（Incident summary） | 一读读完：严重度、时长、范围、影响（会被单独转发引用） |
| 影响 | 影响评估（Impact assessment） | 实测代价：用户/交易/数据/收入，含计量口径 |
| 重建 | 时间线（Timeline） | 从检测到恢复的时序重建（时间戳+来源+时区） |
| 检测 | 检测与告警（Detection and alerting） | 什么报了、什么没报、多久到达能行动的人 |
| 处置 | 响应与缓解（Response and mitigation） | 当时信息下哪些动作有效/无效/加重 |
| 归因 | 促成因素（Contributing factors） | 技术/流程/组织多因素叠加，不塌缩成单因 |
| 系统性 | 系统性条件（Systemic condition） | 使复发成为可能的持续条件（含既往类似事件） |
| 保全 | 做得好的（What went well） | 限损的控制与实践——只列失败的复盘教错课 |
| 行动 | 整改行动（Corrective action） | 责任人+日期+验证方法+对应因素（防/测/缓三分） |
| 存疑 | 未决问题（Open question） | 未能确定什么、什么证据能定论 |
| 附录 | 支撑证据（Supporting evidence） | 日志/图/配置/trace（高密度，为核验组织） |

## 3. 节奏要点

- **事实在解释前，解释在行动前**；「发生了什么的重建」与「本应如何的评判」
  绝不同页——受众先接受事实，再掂量分析。
- 每页一个事实/一个因素/一个行动，标题写它确立了什么；时间线条目带
  时间戳、来源、时区。
- 观察事件、推断序列、促成因素、假设**四类措辞分明**，未确认的标注未确认；
  归因于条件与系统，点名角色与系统、不点过错人。
- 报实测影响，不报最好保护团队的那个估计；底层条件未除，因素不得关闭为已解决。

## 4. 与论证模式轴的关系（正交声明）

- 本条管事故评审的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **中性简报**（源声明 Preferred Mode: briefing；主题标题、完整可扫、时间线
  证据页），行动承诺页可辅**结论先行金字塔**。
- 不重叠：中性简报定「怎么证——无论点的完整可扫证据陈述」；本条定「无责
  复盘的时序叙事页序、事实/解释分页纪律与四类主张措辞」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：风险（risk）、缓解措施（mitigation）、管控措施（controls）、参考文献（references）
- 节奏签名：先风险后管控（risk-then-control）、
  证据简报+决策条（evidence-brief-with-decision-strip）
