## 回路图（四条）

**回路 A · 数据饥饿（平衡/失衡型，时滞数周至数月）**：R-71+R-76 把错误拦截在付费前 → 错误维度样本（backend_stats/run-ledger/sample-decision 的返工与打回）变稀 → R-74 ground truth、R-83 重启裁决、R-79 部分数据信号变弱。限定：只饥饿"错误信号"维度；R-70 回放集口径已绝缘；单机单用户 run 量是天然放大器。缓解：把"上游拦截"变成数据——R-77 补登"预览拦截轮次/原因类别"派生字段；R-74 倾向选项 (a) 标注集（回放有幸存者偏差）；R-83 接受回放/合成证据。

**回路 B · OCR 门栖息地收缩（增强/恶性，R-70 转正后数月显形）**：组合页转正 → 纯图像实质文字页持续缩 → R-73 校准集采集期拉长至数十 run → 门卡 WARN（算力持续支出、拦截寥寥）→ 边际价值衰减。v1.1 只修时序未给退出条件。缓解：开工前 scope 门（lane 占比实测 <15% 触发降级/关闭）+ provenance 判域 + WARN 算力成本入披露。

**回路 C · 路由建议冷启动信任损耗（增强，可翻转）**：初期无 ground truth → 一次劣质建议 → 信任降 → 偏离未记录 → 建议持续疲弱。翻转条件：偏离行为结构化记录。缓解：置信分层呈现（未验证前"规则建议"措辞）+ 回放集离线验证 + 偏离率进 R-77。

**回路 D · 预览迭代驻留（平衡/自限，风险低需监测）**：修订轮次本身是隐藏等待增量。缓解：R-77 聚合"样张门母版修订轮次"，超预算（如 3 轮）门消息诚实披露驻留。

## Findings

- **F5-1 [高] 回路 A**：R-83 的燃料（接受/打回对子）被 R-70（重确认减少）与 R-71（打回前移到不写入正式状态的预览阶段）双重削减——偏好信号迁移到不存在的账本里。→ R-77 补预览拦截派生字段；R-74 验收注选项 (b) 幸存者偏差声明；R-83 重启接受回放/合成证据不设 live-run 硬门。
- **F5-2 [高] 回路 B**：R-73 可能建成永久 WARN 的门。→ 开工前 scope 门 + provenance 判域（禁用路由启发式判域）+ WARN 算力成本入交付披露。
- **F5-3 [中] 回路 C**：冷启动期"推荐默认"包装未验证规则。→ ground truth 未达阈值前呈现"规则建议（未经本地数据验证）"措辞；规则表先在 R-70 回放集离线验证；R-77 加建议偏离率。
- **F5-4 [高] 偏斜**：R-70 分阶段期至少三个"页型全集"版本（v0/v1/v2），R-73/74/77/78 各自隐含版本不同步；传播链示例：v1 窗口概念页被路由 composite → 3a 以 TF-2 fallback 语义兑现 → 披露条款误判假红灯；回滚时 provenance 消费者需优雅降级。→ **页型清单单一真值源**：R-70 交付版本化页型注册表（page_type_regime：页型枚举×lane 映射），作为路由/sidecar/R-73 门域/R-74 规则/R-77 分桶/R-78 覆盖的唯一口径；工件携带 regime 版本；bump 触发校准重采集与规则迁移。
- **F5-5 [高] 边界**：R-71 预览（预测性）与控制台 FR4/5（报告性）两套预览体系无联动声明；"骨架"一词双重语义（R-71 有布局的预测 vs 控制台灰块占位）；R-78 与 lightbox 各建移动放大；简报与时间线数字双口径面。→ 渲染路径不统一（信任语义不同），统一三件事：①路径约定（R-71 落 `<run>/previews/`、R-78 落 run workspace，控制台 FR5 增"样张门基线"入口按路径 serve，不建第二查看器）；②术语切分（控制台灰块改"占位"）；③数字单一来源（R-77 与控制台 FR7 共享聚合或加公式对齐测试）；简报=决策时刻要求动作，时间线=旁路观察。PRD 增"关联 PRD"节。
- **F5-6 [中] 边界**：本批写侧变更（R-70 换 lane、R-73 拦截事件、R-81 调度）会击穿控制台 FR4 的 run.log 行推断启发式，无回归责任方。→ 新增 reason code 与页级失败事件一律结构化写入 events.ndjson 作为读侧契约；R-73/R-81 验收加"控制台页态推断回归用例"。
- **F5-7 [中] 边界**：R-71 预览-成品一致性依赖 dashi U3 无版本钉扎；默认绑定代表性不足会制造假否定。→ 预览 provenance 记录 U3 契约版本；加"预览 vs 成品同页漂移"回归 fixture；对照锚点页覆盖默认绑定页。
- **F5-8 [低] 回路 D**：修订轮次无度量无披露。→ R-77 聚合样张门修订轮次；超 3 轮门消息一行披露（纯披露不新增轮次）。

## 总体结论

两两交互已被上轮打磨扎实，但系统层有两个未承认的结构性事实：①本批同时含"压制错误的特征"（R-70/71/76）与"消费错误的特征"（R-73/74/77→83），前者成功结构性抽干后者燃料——不解锁"拦截即数据"，飞轮后段空转；②与三个外部系统（控制台/dashi/evals）共享工件与呈现面却零跨 PRD 声明。四个高严重度缓解全部加性，不触门语义/红线/轮次。

## 一句话立场

微观时序已收紧，宏观欠两件事——把"上游拦截"记为数据、把页型全集建成带版本的真值源，否则 R-70/71 的成功会以 R-73 报废、R-74/83 长期搁浅的形式收系统级利息。
