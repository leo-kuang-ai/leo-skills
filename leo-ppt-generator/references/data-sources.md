# 数据通道登记（R-05）

> 加载阶段：`execute` 内用户明确要求市场/行业数据时读取；不得在入口 / advise 阶段读取。
> 来源：专家5 E5-06。只登记通道与回溯格式，**不写任何密钥/凭据字段**（通道本身无需凭据）。

## 回溯格式（强制）与边界

经登记通道取的每个数据点：**来源 URL + 抓取时间戳（ISO8601 UTC）写入
sources-manifest**（引用级，数据表入素材库走 R-04）。抓取不到时**如实标 unknown
求证**，禁止编造数字或来源；**不做爬虫/登录态采集**。研究综合（数据怎么选、怎么
交叉验证）不在本文件——归 Deep Research 侧（专家1）；采集内容只存元数据与引用锚点
（BR-006）；引用文字进页面走三级标注既有合同。

## 登记通道（公共只读 API 形态示例，无需凭据）

| 通道 | endpoint 形态 | 用途 |
|---|---|---|
| 60s API（vikiboss/60s） | `https://60s.viki.moe/v2/60s` 等每日资讯接口 | 每日新闻/热榜数字 |
| DailyHotApi（imsyy/DailyHotApi，自部署） | `GET http://<self-host>/weibo`、`/zhihu` 等平台路由 | 多平台热榜排名 |
| 60s 静态数据 | `https://60s-static.viki.moe/60s/<date>.json` | 按日期回读当日快照 |

自部署通道（DailyHotApi 等）host 由用户环境决定，登记形态不含任何凭据；新增通道须
保持"公共只读 + 无凭据 + URL 可回溯"三条件，否则不入本表。
