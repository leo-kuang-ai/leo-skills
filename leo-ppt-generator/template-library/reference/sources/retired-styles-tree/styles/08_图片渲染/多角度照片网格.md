# 图片渲染：多角度照片网格（multi-angle-grid）

**分类:** 08_图片渲染 · 现代商业

**配对视觉风格:** —（本批新增渲染,无固定 01 配对;可直接点名,默认使用场景见 `00_索引/视觉风格配对.md` 末节）

**定位:** 同一主体的多机位九宫格——远景/中景/特写混排于柔焦自然底,一致光线统一为一项研究

## 1. 风格段落（paste-ready，可直接用于图片生成）

> One subject shot from many vantage points and tiled into a clean nine-square grid — distant, medium, and close-up framings mixing angles and crops against a softly blurred natural backdrop. Consistent light and color unify the panels into a single study. Cinematic and comprehensive — a strong way to present a subject, product, or place from every side on one slide. Rendering guardrails: no text, no lettering, no numbers, no logos, no watermarks inside the image — any typography is applied later by the page layout, never by the image model. Compose for a 16:9 widescreen canvas (2560×1440): wide horizontal frame, not a poster column.

## 2. 线条 · 纹理 · 深度

| 维度 | 处理 |
|---|---|
| 线条质量 | Photographic edges within clean square crops |
| 纹理 | Consistent natural-light grain across panels |
| 深度 | Per-panel depth of field; unified blurred backdrop |
| 材质 | Photography grid on soft natural ground |
| 情绪 | Cinematic, comprehensive, studious |

> 渲染画法不写死 HEX;源卡参考色板 `#6FA8DC / #7FA05A / #E8E2D0 / #3B3B3B（首色为 accent）` 与信息密度 `medium` 仅作 deck `colors` 锚点缺省时的默认建议。适用场景（源自卡 tags）：产品全览页 / 场地/对象研究 / 细节展示 / 综合呈现。
