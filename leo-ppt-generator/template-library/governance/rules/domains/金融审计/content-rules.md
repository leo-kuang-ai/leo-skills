# 金融审计 内容规范（content_rules）

> 路由命中金融审计行业域时强制挂接本文件。

## 术语表

- 术语首现＝全称（缩写）：净资产收益率（ROE）、管理规模（AUM）等。
- 口径词区分使用：报告期/经调整/备考（pro forma）；不得混用。

## 禁用与必用表述

- blocked：向不特定对象宣传私募产品（面向公开 deck 即触发）；"保本保收益""预期收益率""稳赚""刚性兑付"
- rewrite：业绩陈述改为带期间与口径的事实句
- annotate（必用表述）：前瞻性陈述必带免责句；过往业绩必标"不预示未来表现"；私募场景必带合格投资者提示

## 数字标注规范

登记表必填字段：来源 + 期间（报告期） + 单位（含币种与量级，如"人民币百万元"） + 口径（报告/经调整/备考）。对比断言必带基准期间（comparison_baseline），无基准按编造阻断。估值与预测数字必须标"估算"。

## 图表与图形惯例

- 财务图形优先：桥图（walkthrough 步骤标注）、同比/环比带基准期间标注
- 静默期信息禁入任何页面

## 场景力度表

| 表述 | 内部分析 | 对外募集/宣传 |
|---|---|---|
| 未审计预测数字 | annotate（标"估算"） | blocked（无合规包装时） |
| 历史业绩对比 | annotate | annotate + 免责 |

## 合规红线

- 静默期信息入页 → blocked
- 私募产品对公开受众 → blocked
- 保本保收益类表述 → blocked（rewrite 后复核）
