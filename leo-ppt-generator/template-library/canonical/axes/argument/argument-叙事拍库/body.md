# 叙事拍库：叙事方法论层的选配组件（arc_beat 精选）

> **层位声明**：本库服务 `叙事方法论/` 子层（叙事层管「怎么说」——页序骨架与节奏）；
> 论证模式五/六轴（`../学术五拍.md` 等）管「怎么证」——证据义务与论证骨架；
> RST 关系（[`../../../../../references/rst-paging.md`](../../../../../references/rst-paging.md)）管「哪些内容必须同页/拆页」。
> 三层正交：选叙事方法论不替换论证模式，也不改写 RST 分组。
> 与 `../13_页面语义/` 的边界：页面语义是**单页**功能词表（封面/漏斗/对比……），
> 拍（beat）是**叙事弧上的节位事件**——一拍可落在不同语义页型上，二者不互相枚举。

**来源**：presentation-skill 的 style_token_atlas.json（2026-08-31 进货，
atom_type_counts: arc_beat 33 / rhythm_signature 12）。
**选录口径**：频次 ≥120 的 19 拍全收，另以最高区分度（34.47）收 `decision`
（与 roadmap/workflow 同频 60，取区分度破同频）——共 **20 拍**；节奏签名 12 全收作参考。
**白名单纪律（M1 评估结论）**：拍**不自由组合**——仅可出现在叙事方法论条目
第 5 节声明的白名单内；未声明拍配额的叙事不取拍。节奏签名为节奏倾向参考，
不构成独立取值。

## 3. 未收录说明（33−20=13 拍）

频次 <120 且未破同频入围的 13 拍不入库：roadmap / workflow / status / cohort /
operations / demo / model-card / security / ask / financials / model / outcomes /
risk-benefit——多为单家族专用（lavender-ops、midnight-neon、executive-clinical、
sunset-investor）或语义已由叙事条目页序骨架直接承载（如 ask 由融资路演的
「要价」节位承载）。需要时按本库同款口径复审增补，不得绕过白名单纪律。
