# 版式：P32 · Agenda · 目录议程

**分类:** 12_版式库（导航结构版式）

**用途:** deck 目录页 / 章程议程页 / 汇报路线预告。

**适用内容类型:** **3–6 个章节条目**(每条 = 编号 + 章节名 + 一行说明,不展开)。条目 >6 改用 P15 Image Matrix(纯文字场景去图);只有单一主题宣言时改用 P3 Statement。**不承载数据**;需要给每章配数据预告的改用 P16 Multi-card Brief。

**骨架:** 顶部 kicker(「AGENDA / 目录」)+ 页标题(h1 8.4vw)/ 下方 3–6 行议程条目,每行 hairline 分隔:左列编号巨字(4.8vw,限高 `min(4.8vw,8vh)`,weight 200)+ 中列章节名(h3 4.4vw)+ 右列一行说明(caption 1.6vw,灰)/ 行间距用 grid gap,不叠 margin。

**关键类:** `.agenda-list` `.agenda-row` `.agenda-num` `.agenda-note`

**动效 recipe:** `agenda-walk` — 条目逐行入场(180ms/行,编号先现、文字后入),当前章节行可加 accent 左边线

> 版式是「页级可粘贴结构」，约束内容类型匹配（见 `选版式P0原则.md`）。目录页的承诺必须兑现:议程条目名与后续章节标题逐字一致。数值呈现遵守 `00_索引/图表样式规范.md`。
