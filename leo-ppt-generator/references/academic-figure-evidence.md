# 学术图表证据规则（academic figure evidence）

> **加载阶段**：本文档仅在 `execute` + Route=`generate`、进入母版制作阶段
> （工作流第 3 步）且材料含图片证据或学术场景时按需读取（与
> [`deck-master.md`](deck-master.md) 同批）；不得在入口或 Route 判断阶段读取。
> 分工边界：图怎么「处理与审查」归本规则；图怎么「画」归
> `../template-library/governance/authoring/index/图表样式规范.md` 与风格库。

## 1. 选图先于版式

每张进入 deck 的图必须回答一个明确的演示问题（即母版图行的「焦点」与「服务」
字段）。说不清这张图承载哪个结论元素、服务哪组比较的图，就是没被读懂的图——
删除或标 `not-use`，不得为了「显得读过论文」而保留。

## 2. 六种处理模式（封闭枚举）

入 deck 的每张图在母版图行声明且仅声明一个处理模式：

| 模式 | 含义 |
| --- | --- |
| `preserve` | 整图保留，不裁不拆 |
| `overview+detail` | 总览图 + 已有独立面板或用户提供的细节图组合讲解 |
| `split` | 独立面板分页讲解，保留标签与上下文 |
| `cross-slide` | 一张核心复杂图跨多页逐部分讲解 |
| `not-use` | 不用：无关 / 不可读 / 重复 / 误导 |
| `request-higher-resolution` | 关键图无法忠实呈现时，先向用户求高清源 |

**本地裁剪不是默认能力**：全图密集或比例不佳时，优先顺序为 preserve →
cross-slide → 已有独立面板 → 求高清源 → 弃用（`not-use`），不得直接上手裁剪。

## 3. 图视觉审查五级状态（封闭枚举）

每张图声明审查状态，标记 agent 实际「看」这张图到什么深度：

| 状态 | 含义 |
| --- | --- |
| `vision-reviewed` | 真打开图看过内容 |
| `metadata-reviewed` | 只看了尺寸、页码等元数据 |
| `caption-inferred` | 仅从图注推断 |
| `user-described` | 依用户口述 |
| `not-reviewed` | 未审查 |

**位置性标注门槛**：只有 `vision-reviewed` 的图，母版与派发提示词中才允许出现
基于图内位置或图内结构的标注（如「高亮右上子图」「箭头 ② 指向的通路」）；
其余状态的图带此类标注即判 `figure_review_status_insufficient` 打回——没看过
大图却描述图内位置，等于编造。

## 4. 原图裸上纪律

学术证据图默认**不加任何容器装饰**：不加边框、卡片、白色垫板、圆角容器、
阴影，直接坐在版面上。轴、图例、单位、比例尺、panel 标签、表头必须完整可见。
多图区分靠留白、对齐、编号与简短图注，不靠包框。禁止自动「高亮区域」式裁剪。
高危拆分、跨页讲解、核心证据替换必须经用户确认或明确披露（寄生母版确认点，
不新增确认门）。

## 5. 图过多 / 过小的降级顺序（固定次序，不可跳步）

1. 删掉不推进论证的图；
2. 减少解释性结构（辅助箭头、复述文字）;
3. 放大关键图；
4. 不同证据拆页；
5. 对密集核心图改用 `overview+detail` / `split` / `cross-slide`；
6. 省略撑不起可读页的次要证据。

不得把多图缩成不可读缩略图来「证明读过论文」。

## 6. 母版图行绑定语法（机读）

含图页在母版视觉行下逐图登记图行，`check_master_contract.py` 按本语法校验：

```text
图[F3] 模式:preserve 状态:vision-reviewed 焦点:消融对比的主表
承载:表2的误差线与均值 | 服务:方法A与基线的显著性比较 | 避免误读:误差线不等于统计显著性
```

- `figure_id`（`F<数字>`）deck 内唯一；`焦点`（这张图回答的演示问题）必填；
- `模式` / `状态` 必填，取值在上述封闭枚举内；
- 三段（`承载` / `服务` / `避免误读`）齐备：承载元素是图中实际支撑结论的部分，
  服务的比较是本页论证用途，避免误读是听众最可能犯的读图错误；
- 语法可写单行或两行（三段换行续写）；无图页不写图行——不含图行的母版
  天然合法（向后兼容）。

## 7. 公式与数值保真

- 方法页如含公式，必须保留 LaTeX 原式并附变量解释（引用级）；
- 表格 extract 必须携带真实数值，不得四舍五入后重写、不得「约化」量级；
- 单位、坐标系、基线口径随图行三段一并交代，禁止省略后靠口头补。

## 8. 与既有真值的关系

- 图的**来源三级**（实拍 / 生成-氛围 / 生成-示意，deck-master 视觉行）继续管
  来源等级；本规则管**处理方式与审查状态**；两者同写一行、互不替代。
- 数据页数值仍按 `../template-library/governance/authoring/index/图表样式规范.md` 的置信度形状语法标注。
- 数字类元数据（verified? / as-of）走母版数字登记表，不在图行重复。
