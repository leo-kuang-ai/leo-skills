# 图片渲染：金句衬线卡（golden-serif-quote）

**分类:** canonical/axes/rendering · 叙事氛围

**配对视觉风格:** —（本批新增渲染,无固定 01 配对;可直接点名,默认使用场景见 `template-library/governance/authoring/index/视觉风格配对.md` 末节）

**定位:** 暖棕金句卡——一侧柔化人像、一侧超大浅金衬线陈述位,编辑级克制,一页一句 memorable line

## 1. 风格段落（paste-ready，可直接用于图片生成）

> Warm brown canvas with a single light-gold serif voice. A portrait anchors one-third of the frame behind a soft gradient fade while an oversized subtle quotation mark and one large serif statement command the remaining two-thirds. Intimate, editorial, and quietly premium — built for a single memorable line per slide. Rendering guardrails: no text, no lettering, no numbers, no logos, no watermarks inside the image — any typography is applied later by the page layout, never by the image model. Compose for a 16:9 widescreen canvas (2560×1440): wide horizontal frame, not a poster column.

## 2. 线条 · 纹理 · 深度

| 维度 | 处理 |
|---|---|
| 线条质量 | Soft-edged photographic fade against calm serif shapes; no hard outlines |
| 纹理 | Gentle gradient falloff around the portrait; warm paper-grade grain |
| 深度 | Two-zone figure-ground — portrait recesses, statement slot advances |
| 材质 | Warm brown paper + light-gold serif plate |
| 情绪 | Intimate, editorial, quietly premium |

> 渲染画法不写死 HEX;源卡参考色板 `#C9A24B / #3B2A1F / #E8D9BE（首色为 accent）` 与信息密度 `low` 仅作 deck `colors` 锚点缺省时的默认建议。适用场景（源自卡 tags）：金句页 / 证言页 / 人物侧写 / 章节开篇。
