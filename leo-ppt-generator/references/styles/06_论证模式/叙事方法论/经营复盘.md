# 叙事方法论：经营复盘（operating-review）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../rst-paging.md`](../../../rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../叙事拍库.md`](../叙事拍库.md)）。

一句话：周期性经营评审叙事——把**结果、偏差、原因、认领的承诺**分开陈述，
不软化坏数字；深度随重大性而非议程对称。

## 1. 适用场景

季度/月度经营会、业务复盘、OKR 评审、部门经营汇报——受众周期性回流、
需要「比较而非重新定向」的场合。

## 2. 页序骨架

节位序列（页面形态跨期保持稳定，让回流受众用眼睛比较；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 记分 | 期间记分卡（Period scorecard） | 对计划的完成面一页可读 |
| 结果 | 计划对结果（Result against plan） | 标题写结果与其方向，确立它的数字在页面上 |
| 轨迹 | 趋势与走向（Trend and trajectory） | 走势与拐点及其成因 |
| 偏差 | 偏差驱动（Variance driver） | 解释最大部分偏离的那个原因+其证据 |
| 分解 | 分部拆解（Segment breakdown） | 业务单元/产品线切面 |
| 异常 | 异常与观察项（Exception and watch item） | 未达偏差量级但需盯住的事项 |
| 行动 | 纠偏行动（Corrective action） | 认领的行动+日期（每个解释以行动收口） |
| 兑现 | 上期承诺状态（Prior commitment status） | 上期承诺的逐项兑现 |
| 展望 | 预测与假设（Forecast and assumption） | 预测挂假设 |
| 附录 | 支撑明细（Supporting detail） | 高密度明细 |

## 3. 节奏要点

- 开在简报的水位——期间结果平铺直叙，不重述受众已持有的背景；每个实质
  偏差按金字塔解决一个问题的完整链走：**偏离→解释大头的归因→归因的证据
  →认领的响应**。
- 在计划的指标一行带过，评审时间花在**变化**上；业务单元的排列顺序
  不得替代轻重顺序。
- 实际、计划、预测、上期**四值显式标注、不可互换**；坏消息与好消息同声量
  同显著度呈现；**绝不回溯改目标把 miss 改成 hit**；归因须有证据，没有就说
  「原因未明」。

## 4. 与论证模式轴的关系（正交声明）

- 本条管经营评审的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **中性简报** + **结论先行金字塔**（源声明 Preferred Mode: custom，
  briefing + pyramid：简报水位开场、金字塔链解偏差）。
- 不重叠：两论证模式定「怎么证——完整可扫陈述与结论先行链」；本条定
  「跨期稳定页形的评审叙事、四值标注纪律与按重大性分配深度」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：KPI 总览（kpi-summary）、偏差（variance）、趋势（trend）、结果（results）
- 节奏签名：指标驱动董事会备忘（metric-driven-board-memo）、
  经营节拍+状态色（operating-cadence-with-status-color）、
  图表+解读（chart-plus-interpretation）
