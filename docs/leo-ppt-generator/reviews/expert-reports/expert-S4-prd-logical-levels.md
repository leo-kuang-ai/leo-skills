# 专家报告 S4 · 逻辑层次（抽象层级与可追溯性）

- 评审对象：PRD v1.2 · 方法论：逻辑层次（L0~L4 层级判定 + 目标→验收追溯）
- 日期：2026-09-11 · 独立审查（不重复上轮 47 findings）

## 层级判定标准

L0 原则（裁决该不该做）→ L1 目标（结果状态宣称）→ L2 需求（是什么/必须/禁止，换实现仍成立）→ L3 验收判据（完成客观判定；可替换性测试：换验证手段即失效=实现指示）→ L4 实现指示（怎么造测试/载体/协议模板/排期）。**宣称守护测试**：防"宣称与事实不符"（CI 下界/口径锁定/否定感知）→ L3 合法；防"实现者选错工具"（fixture 工厂/socket 夹具/脚本先例）→ L4 应迁出。

## Findings

- **F4-1 [高] 迁移**：R-70 验收 3 是完整实验设计方案（人数×组数×量表×盲法×维度×复评上限×协议先例文件路径）；按可替换性测试只有通过线数值是 L3，其余是 L4 评测设计。→ PRD 留判据一句（均分非劣 −0.5+融合度单项线+协议留档可审计），实验设计迁评测设计文档/附录。
- **F4-2 [高] 迁移**：测试基建设计注入验收——R-77 指定 fixture 工厂名与只读断言实现形式、R-71 指定 socket 夹具双层载体、R-70 指定注入点与拒绝者脚本先例。→ 留"【单测】只读性可被机器断言"级判据；载体选型迁出；`/leo-fonts/` 豁免是口径澄清应留。
- **F4-3 [中] 迁移（含保留切分线）**：统计方法学分层——样本量下限、未达规模如实报、CI 下界判定、口径锁定是合法判据硬化**保留**；k 折 vs 分集二选一、样本量反推公式、fixture 冻结机制是验证方案设计**迁出**。
- **F4-4 [高] 追溯缺口（三条无牙目标）**：(a) R-71"返工在付费前暴露"无效果验收（只有呈现过程合规）——补【run-留痕】"授权后母版/版式类修订轮次较基线期不上升"；(b) R-73"AI 目视 QA 不再承担可机判对齐"无验收——补"visual-qaf 逐字对齐职责移交后清单同步修订"合同判据；(c) R-77"数据底座"仅必要非充分覆盖（轻微）。

- **F4-8 [中] 根因（对照 run-vis PRD）**：run-vis 评审吸收有"需求化改写"过滤层（实现层备注标注后留审查记录不进 FR 正文）；本 PRD"47 项全部吸收"管道缺过滤层，评审意见原样沉积为验收标准。→ 立吸收规则："吸收=改写为验收判据或需求约束；实现细节降级为附录'实施线索'并标注来源 finding，不进验收正文。"

- **F4-10 [低] 边界判例**：指标派生公式（TF-2=text_fallback 计数等）是需求级定义保留；"须先补登 reason code"是实现任务清单迁出；"按 sha256 差集增量重建"算法选型迁出（"增量更新"保留）；ground truth 二选一方案设计迁评测设计（一致率阈值保留）。

## 总体结论

**L3 骨头硬、L4 渗漏重**：全局验收纪律是仓库最佳 L3 治理文本；v1.1 注入中判据硬化部分合法高价值不应误伤。层级串味集中三条沉积带：验收内"怎么测"尾缀、【人工-协议】携带完整实验协议、§3 计划节；根因是吸收管道缺过滤层。追溯缺口：P2 目标行断链、三条无牙目标、一处强度落差。处置：v1.3"验收判据纯化"——迁移而非删除（落附录"实施线索"回链 finding），补 R-71/73 效果判据与 P2 目标行。
