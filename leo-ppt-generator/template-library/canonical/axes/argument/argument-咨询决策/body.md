# 叙事方法论：咨询决策（consulting-decision）

> **叙事层**条目：管「怎么说」——页序骨架与节奏；「怎么证」由论证模式轴承接（配对见第 4 节），
> RST 关系管同页/拆页（[`../../../../../references/rst-paging.md`](../../../../../references/rst-paging.md)）——三层正交。
> 拍选配仅白名单（第 5 节，源 [`../argument-叙事拍库/body.md`](../argument-叙事拍库/body.md)）。

一句话：**答案先行**、证据领路的决策文档方法——先给总答案，再给关键支撑、
每页证据与未决假设，让决策者在最短路径上抵达可执行的判断。

## 1. 适用场景

决策备忘、咨询建议书、管理层决策会、投资/取舍决策文档——一切
「受众带着一个待定决策而来」的汇报叙事。

## 2. 页序骨架

节位序列（非页数模板——页数按材料量与禅档位定；同页/拆页按 RST 关系）：

| 节位 | 页角色（原文） | 沟通任务 |
|---|---|---|
| 总览 | 执行摘要（Executive synthesis） | 一页读完：决策问题、总答案、关键支撑 |
| 建议 | 推荐方案（Recommendation） | 推荐什么、达成什么 |
| 情境 | 情境-复杂化-解决（Situation-complication-resolution） | 受众已知情境 + 新复杂化 + 本文解法 |
| 拆解 | 驱动因子分解（Driver decomposition） | 答案按 MECE 驱动因子分解 |
| 诊断 | 现状诊断（Current-state diagnosis） | 现状证据与病根 |
| 标杆 | 对标（Comparison-benchmark） | 与标杆/可比项的直接对照 |
| 方案 | 流程与运营模型（Process-operating model） | 怎么运转、谁做什么 |
| 路线 | 路线图（Roadmap） | 分阶段落地 |
| 风险 | 风险与缓解（Risk-mitigation） | 假设、敞口与对策 |
| 附录 | 证据附录（Appendix-evidence） | 支撑细节 |

## 3. 节奏要点

- 全程维持可追溯链：**总答案 → 关键支撑 → 页讯息 → 证据**；序列适配项目，
  不强加固定节位清单。
- 每页一个统辖问题，断言式标题作答，证据醒目地置于答案之下/之旁。
- 事实、假设、推断、建议**四类措辞语义分明**；未获支撑的主张不得升格为结论。
- 建议与推断的措辞全场一致，前后不漂移。

## 4. 与论证模式轴的关系（正交声明）

- 本条管决策文档的**页序与节奏**；论证形态由论证模式承接——推荐配对：
  **结论先行金字塔**（源声明 Preferred Mode: pyramid；SCQA、断言标题、MECE 分解）。
- 不重叠：金字塔定「怎么证——结论先行的论证骨架」；本条定「决策叙事按
  统辖问题组织页序、四类主张措辞纪律与追溯链节奏」。

## 5. 拍库白名单（选配组件，非自由组合）

- 白名单拍：决策（decision）、风险（risk）、缓解措施（mitigation）、参考文献（references）
- 节奏签名：指标驱动董事会备忘（metric-driven-board-memo）、
  证据简报+决策条（evidence-brief-with-decision-strip）
