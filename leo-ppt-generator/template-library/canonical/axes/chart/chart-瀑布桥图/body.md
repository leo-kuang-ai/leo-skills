# 图表语法：瀑布桥图（Waterfall / Bridge）

**适用内容类型:** 数值从起点到终点的分步增减（利润桥/成本 walkthrough/差异分解）。

**必填字段:** 起点值、终点值、每步增减值与标签；增/减用方向编码（非颜色唯一——需箭头/符号第二线索）。

**画法约束:** 每步浮动柱由累计值决定高度；总计柱落地；步长标注值+方向符号；不允许无来源的中间步（每步必须可追溯到登记表行或合同要素）。

**置信度语法:** 估算步用 ~ 前缀+虚线边（见 template-library/governance/authoring/index/图表样式规范.md）；示意值禁入本图型。
